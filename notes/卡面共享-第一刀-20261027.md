## 这一刀改了什么

### A. 170 区：直接子卡的 使命 ＋ 现状（需求文档不给）

**和 read_card 是同一份事实，不用为了确认再读一遍**；要需求文档或孙级才需要 read_card。

依据：改前区域说明只讲自己的三块，一个字没提子卡区——模型是从区头猜的。

# 第二刀：edit_card 改成精准编辑（12:10，用户指令）

> 「接着，把你编辑卡面的工具迭代了，改成精准编辑」

## 改了什么

`edit_card` 的语义从**整篇覆盖**换成**精准替换**：

| | 改前 | 改后 |
|---|---|---|
| 入参 | `content`（整份正文，按三个区头分段） | `block` ＋ `old_string` ＋ `new_string` ＋ `replace_all?` |
| 落点 | 三块一起写（没写到的块被清空） | **只写目标那一列**，另外两块不进写入参数 |
| 找不到原文 | 不存在这个概念 | 拒，**卡面零改动** |
| 出现多次 | 不存在这个概念 | 拒，要求给更长上下文或 `replace_all=true` |
| 回执 | `{ok:true}` | 改了第几行 ＋ 改前改后片段 ＋ 变了的块全文 ＋ 各块字数 |

保留：`list_versions` / `restore_version`（版本查看与回退仍挂在这个工具上）。

**整块重写仍有各自通道**（这是能删掉整篇覆盖的前提）：
`update_status(content=)` 写现状、`append_ruling(text=)` 写需求文档、
`set_child_mission` 由上级给子树内卡设定使命。

**使命锁对精准编辑同样生效**——它不是绕过闸的后门。

# 第三刀：edit_card 加**行级定位**（12:30，用户指令）

> 「不止要对应哪一块，还要精准可以操作某一行」

## 两种定位，二选一

| 定位方式 | 入参 | 语义 |
|---|---|---|
| 按内容 | `old_string` ＋ `new_string` | 那一块里找到这段、换成那段（须唯一） |
| **按行** | `lines="12"` / `lines="12-15"` ＋ `new_string` | 替换该行区间；`new_string` 为空＝**删掉这几行** |
| **按行插入** | `insert_after=N` ＋ `new_string` | 在第 N 行之后插入（`0`＝插到块首） |

- 行号**以当前块为准**（1 起算，含两端），不是整张卡的行号
- 越界（`0`、超出总行数、`9-3` 这种起>止）⇒ **拒，且卡面零改动**
- 两个定位器同时给 ⇒ 拒（不猜）
- 回执给 `mode`、`at_line`、**被替换的原行**（`before`）——行号会漂移，回执让人当场核对没改错行

## 为什么还要保留 `old_string`

行号会漂移：读卡到写入之间别人改了这块，行号就错位。按内容定位天然抗漂移，是首选；
按行定位用于「这一行太长、懒得抄原文」或「按位置删一行」这类场景。
两者并存，不是二选一留一个。

越界拒且零改动／两个定位器互斥）。

# 第四刀：标点归一化匹配（12:45，用户裁定「按它的做」）

参考 Codex `codex-rs/apply-patch/src/seek_sequence.rs` 的做法：定位前把「长得一样、
编码不同」的字符统一成 ASCII 再比，**写回仍用卡面原文**。

## 解决什么

模型抄原文时把中文标点抄成 ASCII：`“ ”` → `"`、`—` → `-`、全角空格 → 半角。
肉眼一模一样，逐字节不等 ⇒ 明明在卡面上却报「找不到原文」。

## 映射范围

| 类 | 映射 |
|---|---|
| 破折号（U+2010–2015、U+2212） | `-` |
| 弯引号（U+2018–201F） | `'` / `"` |
| 特殊空格（U+00A0、U+2002–200A、U+202F、U+205F、U+3000） | 半角空格 |
| **全角 ASCII 段（U+FF01–U+FF5E）** | 半角（`：，（）；` 等）——**比 Codex 多这一条**，因为我们的卡面是中文 |

**不做**：`「」『』《》` 不映射——它们与 ASCII 引号字形不同，混用不算「编码差异」，宁拒不错。
**也不做**：空格数量差异（原文没有空格、old_string 有）——同样宁拒不错。

## 三条不变量

1. 归一化**只用于定位**；写回卡面的永远是原文（否则会把中文标点改坏）
2. 归一化后仍要求**唯一**，多处命中照样 `ambiguous` 拒
3. 归一化命中时回执 `matched="normalized"`，`before` 给**卡面真实原文**，
   并附 `note` 说明"你给的 old_string 与原文在标点编码上不同，以后引用以 before 为准"

第 3 条是必须的：否则模型会以为卡面写的就是它抄的那版，以后引用就错。

核心面 10 文件：**96 passed / 28 skipped / 1 failed**（既有 `WinError 32`）。
