## 2. 模型配置

- 默认模型：`system.default_model`；回落链 `system.default_model` → `_first_model_key()`（模型目录第一键）→ `""`，不猜名字。`src/api/model_config.py:54-73,407-409`。
- 按节点类型设默认：`card_type_models()` 读 `config/card_type_models.json` 的 `types`（type→模型键）；`_policy_value` 在无 tier/bindings 时查卡类型模板。`src/api/model_config.py:286-290,455-467`。
- 节点级覆盖： per-card 行存于 `works/{work_id}/model_config_table.json` 的 `cards[card_id]`（model/bindings/fallbacks/src）；`pick()` 读该行，缺失时按默认策略填一次（自愈）。`src/api/model_config.py:362-391`, `src/storage/model_override.py:184-189`。

## 3. 密钥处理

- 存储位置：`.env` 文件（`BASE_DIR/.env`，即 `D:\AI_station\推演agent\.env`），键名由各 provider 的 `api_key_env` 字段引用；mavis 走 broker 租约（`auth: broker`）不读 env。`src/api/env_store.py:33-34`, `src/api/settings_api.py:112-121`。
- 是否加密：**不加密**，明文存 `.env`。`src/api/env_store.py:68-89`（read_keys 直接读值）。
- 接口返回遮蔽：`env_store.mask` 只留末 4 位，其余盖成 `····`；`list_key_status` 返回 `{configured, tail}`（tail 为末 4 位或空）。`src/api/settings_api.py` 的 `GET /keys` 与 `GET /models` 只回 `key_status`。`src/api/env_store.py:91-114`, `src/api/settings_api.py:131-140,610-616`。

遮蔽代码原文（`src/api/env_store.py:91-101`）：

```python
def mask(value: str) -> str:
    """打码：只留末 4 位，其余一律盖成圆点。

    "sk-abcdefghijkl" → "····ijkl"（长度不足时全盖，不泄露任何原字符）。
    """
    val = value or ""
    if not val:
        return ""
    tail = val[-4:] if len(val) > 4 else ""
    return "····" + tail
```

`list_key_status` 原文（`src/api/env_store.py:103-114`）：

```python
def list_key_status(path: Optional[Path], names: list[str]) -> dict[str, dict[str, Any]]:
    """逐键报状态：{名: {configured: bool, tail: str}}。

    **明文永不出这里**：已配置且够长才给末 4 位，否则 tail 为空串。
    """
    keys = read_keys(path)
    out: dict[str, dict[str, Any]] = {}
    for name in names or []:
        val = keys.get(name) or ""
        out[name] = {"configured": bool(val), "tail": val[-4:] if val else ""}
    return out
```

- 有无接口能返回明文：**无**。`GET /keys`/`GET /models` 仅 `configured+tail`；`PUT /keys/{name}` 返回 `tail`（末 4 位）不回显 value。唯一返回明文的函数是 `read_keys`（内部），文档声明"调用方（设置接口）只取末 4 位，绝不外传"。`src/api/env_store.py:68-73`, `src/api/settings_api.py:618-640`。

## 4. 配置校验

- 校验发生在**写盘前**。`put_models` 顺序：
  ① `_validate(cfg)` 结构校验 → 失败 400，文件一字不动；
  ② `model_config.compile(cfg)` + `build_gateway(new_config)` 预检构造（纯内存）→ 失败 400，文件一字不动；
  ③ `_backup_current()`；
  ④ `model_config.save(cfg)` 原子写盘；
  ⑤ `model_service.reload_gateway()` 热生效；
  ⑥ 写盘失败时从备份回滚。
  `src/api/settings_api.py:297-376`。

写入顺序代码原文（`src/api/settings_api.py:318-367`）：

```python
    # ① 结构校验
    errors, warnings = _validate(cfg)
    if errors:
        return JSONResponse(status_code=400, content={"ok": False, "errors": errors})

    # ② 预检构造：「建」必须在「写盘」之前。抛错 → 400，文件一字不动。
    try:
        new_config = model_config.compile(cfg)
        build_gateway(new_config)
    except Exception as exc:  # noqa: BLE001
        logger.warning("设置保存预检构造失败: %s", exc)
        return JSONResponse(status_code=400, content={
            "ok": False,
            "errors": [f"新配置无法构造网关: {type(exc).__name__}: {exc}"],
        })

    # ③ 备份当前
    backup = _backup_current()
    backup_name = backup.name if backup else None

    # ④ 原子写盘
    try:
        model_config.save(cfg)
    except Exception as exc:  # noqa: BLE001
        logger.error("设置保存写盘失败: %s", exc)
        # ⑥ 从备份回滚，磁盘复原
        rolled = False
        if backup and backup.exists():
            try:
                _atomic_write_text(CONFIG_PATH, backup.read_text(encoding="utf-8"))
                rolled = True
            except Exception as rb_exc:  # noqa: BLE001
                logger.error("回滚失败: %s", rb_exc)
        return JSONResponse(status_code=500, content={
            "ok": False,
            "errors": [f"写盘失败: {exc}"],
            "rolled_back": rolled,
        })

    # ⑤ 热生效：从磁盘重读重建，一步换单例（不重启、不打断在跑调用）
    try:
        model_service.reload_gateway()
        reloaded = True
    except Exception as exc:  # noqa: BLE001
        logger.error("热重载失败: %s", exc)
        return JSONResponse(status_code=500, content={
            "ok": False,
            "errors": [f"已写盘但热重载失败: {exc}"],
            "reloaded": False,
        })
```

- 校验失败时盘上文件是否保持原样：**是**。结构校验与预检构造均在写盘前；只有通过才 `model_config.save`。`src/api/settings_api.py:318-333`。
- `model_config.save` 原子写：切出旧文件头部注释块保留，`yaml.safe_dump` 生成正文，临时文件 + `os.replace`。`src/api/model_config.py:917-945`。
- `restore_backup`：先 `_validate`（无 `build_gateway` 预检），再备份当前，再 `_atomic_write_text` 写回选定备份，再 `reload_gateway`。`src/api/settings_api.py:667-720`。
- `save_tiers`：校验模型名→`_load_raw`→写 `raw["tiers"]`→`save`→`reload`→网关 config 就地同步→`reseed_tables`。`src/api/model_config.py:725-764`。
- 校验与写盘顺序结论：**校验（结构 + 构造）全部在写盘前；写盘为原子替换；写盘失败回滚；热重载失败不回滚文件**。`src/api/settings_api.py:318-367`。

## 7. 模型网关

- 调用链路：业务调 `model_service.call_main`（`src/api/model_service.py:117-248`）→ `get_gateway()` 单例（`src/api/model_service.py:30-36`）→ `ModelGateway.stream_call`/`call`（`src/model_gateway/gateway.py:454-671`）→ `_stream_once`/`_call_once`（`src/model_gateway/gateway.py:489-750`）→ `_build_options` + `LlmRuntime.stream`（`src/model_gateway/llm/runtime.py:199-262`）→ 已注册适配器 `stream`（OpenAI 兼容 `src/model_gateway/llm_openai_compat/adapter.py:147-218` 或 Anthropic mavis `src/model_gateway/llm_anthropic/adapter.py:99-153`）→ `httpx.AsyncClient` POST `/chat/completions` 或 `/messages`。
- 网关构建：`build_gateway(config)` = `ModelGateway(config)`；MOCK_LLM=1 时 runtime 注册 `MockAdapter`。`src/model_gateway/gateway.py:936-938,276-297`。
- 超时：httpx.Timeout `connect=None`、`read=None`（无空闲墙钟）、`write=30.0`、`pool=30.0`；`STREAM_IDLE_TIMEOUT=None`（`asyncio.wait_for(timeout=None)`）。`src/model_gateway/llm_openai_compat/adapter.py:165-180`, `src/model_gateway/gateway.py:792`。
- 不注入 max_tokens（拆闸铁律）：`_facts_for` 设 `max_tokens=None`；`serialize_request` 仅当 `options.max_tokens is not None` 才写。`src/model_gateway/gateway.py:328`, `src/model_gateway/llm_openai_compat/serialize.py:138-139`。
- 重试策略：每个模型 `retry.max_attempts`（默认 3）/`backoff_seconds`（默认 2）；`retry_grading.enabled` 默认 false，关闭总时长熔断；错误分类 caps `RETRY_CLASS_CAPS`（auth=1, timeout=2, 503=5, rate_limit=5, connection=3, error=3）。`src/model_gateway/gateway.py:70-78,394-409,491-492`。
- 兜底：`call`/`stream_call` 接受可选 `fallbacks` 列表，首选重试耗尽后换同层下一个；`layer_fallbacks()` 恒返回 `[]`（2026-10-26 用户令，不自动换人）。`src/model_gateway/gateway.py:460-487,646-647,752-759`。
- 并发闸：每模型一个 `asyncio.Semaphore`，上限 `concurrency.per_model[model]` 或 `concurrency.default`（默认 3），排队不失败。`src/model_gateway/gateway.py:220-238`。
- 热重载：`model_service.reload_gateway()` 重读+重编译+重建单例，先建后换；在途调用持旧对象。`src/api/model_service.py:39-46`。
- 状态：`RuntimeStats` 累计 calls/tokens/failures/recent(≤100)。`src/model_gateway/llm/runtime.py:49-84`。

## 关键发现

1. 密钥明文仅内部 `read_keys` 可读，API 层只返回 `configured+tail`（末 4 位）；`.env` 明文存储、写入前备份。`src/api/env_store.py:68-73,91-114`, `src/api/settings_api.py:610-640`。
2. 保存顺序为"先验后写"：结构校验 → 内存预检构造 → 备份 → 原子写盘 → 热重载；校验失败文件一字不动，写盘失败回滚。`src/api/settings_api.py:318-367`。
3. `restore_backup` 只做结构校验，不调 `build_gateway` 预检构造，直接写回备份后热重载。`src/api/settings_api.py:690-711`。
4. `prompt_log` 全文落盘 prompts/responses，无脱敏；预算 2GB/3000 份。`src/api/prompt_log.py:123-129,24-25`。
5. 网关无墙钟超时（read/connect=None），不注入 max_tokens；重试分级默认关闭总时长熔断；`layer_fallbacks()` 恒空（不自动换模型）。`src/model_gateway/llm_openai_compat/adapter.py:165-180`, `src/model_gateway/gateway.py:328,646-647,401`。
6. 未解：`roles.json` 未在本次读取范围内；`config/card_type_registry.json` 仅用于 `card_types()`，未单独审计其结构。
