> note 的内容常驻卡片上下文，但其他卡片不能读取。」

## 一、落成什么样

| 项 | 实现 |
|---|---|
| 存哪 | `shadows.note` 列（第五列，与 progress/coordination/artifacts/iterations 并列） |
| 卡面 | 影子多一节 `## 笔记`，排在「迭代历史」之前（内容是内容，留痕是留痕） |
| 常驻 | 150 区渲染出 `【笔记】`，**排最前**——它最该先被看到 |
| 写工具 | **`edit_note(old_string, new_string, replace_all?)`** —— 精准编辑 |
| 私有 | `read_shadow`（自己读）拿全五节；`read_linked(part=影子)`（别人读）**剥掉笔记** |

## 二、为什么是「精准编辑」而不是整块覆盖

`update_shadow` 是四节整块覆盖。笔记如果也整块覆盖，就是 card_067「45,935→351」那类事故的
翻版——**笔记是最容易越记越长、最怕被一次清空的东西**。

`edit_note` 的定位规则照 `edit_card`：

- 找不到 ⇒ 拒，**笔记零改动**
- 出现多次且没给 `replace_all` ⇒ 拒
- 标点编码不同（弯引号/全角空格/全角 ASCII）⇒ 按**归一化**命中，**写回仍用原文**
- 回执带：改了第几行、改前改后片段、改完的笔记全文

**过程中修了自己一个 bug**：第一版精确命中时**漏了多处检查**，会静默改第一处——
与 `edit_card` 的口径不一致。已补。

## 三、顺手把一个既有的谎话变成真的

150 区原来就写着：

```
### 影子（本卡私有，别的卡读不到）
```

**而实际上 `read_linked(part="影子")` 能读别人影子的全文。** 这句话一直是假的。

现在 `read_via` 的影子分支传 `include_private=False`，剥掉 `_PRIVATE_SECTIONS`（笔记）。
这句声明第一次成真。

（注意：四节仍然可沿线路读——那是设计（协作要看对方进度/待协作）。只有笔记是私有的。）

## 五、边界

- **tool 卡也有笔记**：`edit_note` 挂 `shadow_write`，tool 卡同样有这个开关、也派生影子 ⇒
  它的工具面多了这一件（已更新 `test_cardperm_readopen` 的期望集）。我认为合理：它也是卡。
- **笔记不参与四节那套模板/占位符规则**：它是自由文本，`read_note`/`write_note` 只读一列。
- **`update_shadow` 仍然只管四节**：它的 schema 说「有且只有四节」，笔记不在此列。

# 追加：影子四节也改成精准编辑（2026-10-27 深夜）

> 用户：「如果对影子卡编辑也是全块覆盖，那么会有风险，得把影子卡编辑也全部改成精准编辑」

## 做成的

**新增 `edit_shadow(section, old_string, new_string, replace_all?)`**

- `section` 取 进度／待协作事项／产物清单／迭代历史
- 只动指定节里的一处，**其余三节与笔记一个字不碰**
- 定位规则与 `edit_note` **共用同一个 `_patch_text`**（精确命中 → 歧义拒 → 标点归一化兜底），
  不许各写一遍

**存储层配套**：`shadow_store.read_section` / `write_section`（单列读写，只碰那一列）。

## 没做成的：`update_shadow` 没能下线

原本按 `review_request` 的先例「从工具面移除、handler 保留」，`pop` 掉之后**破了 32 个用例**。

根因不是功能问题：**这些测试拿 `update_shadow` 当"构造影子数据"的载体**，而且它们测的正是
权限闸（`shadow_write` 该放行/该拒）——载体没了，闸就没法测。

我试着批量改测试（`execute_tool` → 直调 handler），正则没匹配上；改到一半又因为一处
`\n` 转义写错把 `card_tools` 语法弄坏，回退后时间不够。

**所以现在两条路并存**：

| 工具 | 语义 | 状态 |
|---|---|---|
| `edit_shadow` | 按节精准编辑 | **新增，模型应优先用** |
| `update_shadow` | 整块覆盖四节 | 暂留（handler 也被测试当数据构造器用） |

要真正下线，得先改那 32 个测试的载体——**属单独一轮**，不是改一行的事。
