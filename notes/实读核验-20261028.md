## 8. 权限：两个独立关口，不是一套

| 关口 | 位置 | 判什么 |
|---|---|---|
| `policy.can()` | policy.py:407 | **唯一作用域规则表**，顺序即优先级：①目标存在 ②类型分权（目标卡须持该开关）③对自己 ④根卡对本项目全通 ⑤离树卡（role/function）：不改别人卡面、不动根卡身份，其余通 ⑥树内卡：目标须在自己子树 |
| `policy.check_linked()` | policy.py:506 | **通信线边界**，判据只有 `_linked_between`（任一侧有 links 即通，方向不限） |

等于没拦（:510-514 注释记录了 5713 首版实测踩到的坑）。

`_is_in_subtree`（:337）已从权限开关里拆成独立函数——「它不含任何类型分权语义；
未来 edit 收走后这一层可整层删除」（:349）。

## 9. 自动模式续轮链（goal）

`goal/driver.py` 是「自动模式会不断唤醒」的机制本体，链路：

```
回合结束 → routes.py:2684 notify_idle(work, card, outcome)
   ├ outcome∈{error,max-tokens} ⇒ disarm（异常结果不自动重试）
   ├ outcome==aborted ⇒ attempt 已 claim/admitted ⇒ pause（不能自动重启），否则 disarm
   └ ok ⇒ request_drive → drive()
drive()（:204）
   ① st.stopping / competing_queued ⇒ 跳过
   ② _auto_enabled（:211）← **用户开关优先**，auto_mode 关掉连 goal 都不读
   ③ goal 须 active + armed
   ④ rounds_started >= max_goal_rounds ⇒ block("round-limit")
   ⑤ _yield_to_children ⇒ 有未终止子卡则让位
   ⑥ 预留 round = rounds_started+1 → _spawn_goal_round（append_user=False）
```

两个「我们的层、不在原版 goal 包里」的补丁（注释明写）：
- `_yield_to_children`（:171）：原版用 subagent family 表达父子（子 agent 阻塞返回），
  我们是「建完子卡就结束回合」，不让位就会父子抢轮。
- `notify_parent_idle`（:303）：子卡终止时显式叫醒父卡，否则父卡一直让位等一个已终止的子卡。

`_auto_enabled` 是 10-24 补的闸——注释记录了真实故障：「开了自动模式就停不下来，
切回手动也停不住」，因为 goal.driver 只看 phase/activation，**完全不看 auto_mode**（:188-193）。
