# 03 锚的切换

## 拆解：房子作为锚的三重功能
1. 储值：居民财富约六至七成在房产。
2. 抵押：银行体系信贷的主要抵押品，信用创造的枢纽。
3. 收入：土地出让金 + 地产链税基 = 地方财政的主干。

## 股票能接哪几个
| 功能 | 房子 | 股票 | 判断 |
| --- | --- | --- | --- |
| 储值 | 强（低波动、实物） | 可替代，但高波动 | 中等 |
| 抵押/信用创造 | 强 | 弱（股权质押风险大，银行不愿接受） | **接不住** |
| 融资 | 强（地产链） | 强（科创板/注册制/再融资） | 可替代 |
| 收入 | 土地出让金 | 分红/减持/税费 | 量级待验（见 04） |
| 就业乘数 | 极长地产链 | 间接 | 偏弱 |

## 所以准确的表述
不是"股票接替房子当货币锚"，而是"股票接替房子当**居民财富储值载体 + 产业融资载体**"。货币锚那一环是空的。

## 缺的环（决定成败的四个变量）
1. **居民资产负债表**：居民收入预期不改善、房贷存量不清化，则财富难从房产搬家。
2. **长期资金**：险资、社保、年金权益配置比例是否制度化上升（政策已在推，见 05/07）。
3. **公司质量与分红文化**：分红率、退市制度、股东回报（新"国九条"2024 有相关要求）。
4. **定价治理**：政府既做监管者又是大股东，托市会扭曲定价，反过来损害"锚"的公信力。

## 小结
"科技 + 股票"作为长期方向的判断，**中等置信**；"股票能当货币锚"，**低置信**。原文在这里把两个不同层次的问题合并了。
