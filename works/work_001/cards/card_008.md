# 07 证伪清单

原则：**不能被否证的叙事没有推演价值。**本卡写下"若叙事为真应看到什么"、"看到什么就应放弃"。

## 一、若"股权财政/新质生产力为真"，应看到
1. 国有股权划转社保**常态化、规模化**（而非个案）。
2. 上市公司**分红率系统性提升**，并与国资考核挂钩。
3. 央企/国企**市值管理纳入考核**（2024 已起步，看执行度）。
4. 险资、社保、年金**权益配置比例的制度性上升**（看文件与季报数据）。
5. IPO/再融资**持续向硬科技倾斜**，且容忍短期估值泡沫。

→ 已出现部分正向证据（新"国九条"、市值管理考核、中长期资金入市文件），但**量级与持续性**远未验证。

## 二、若"牛市是政策目标"，应看到
1. 下跌时有托底（已有）。
2. 上涨时**不主动打压**。
3. 官方叙事从"防风险"转向"财富效应/消费拉动"。

## 三、可证伪条件（出现即应下调置信）
1. **上涨被主动降温**（窗口指导、提高交易成本、严查杠杆）→ 目标是"稳"而非"牛"（支持维稳论）。
2. **股权财政量级始终不接土地缺口**，地方仍靠债务与转移支付维持 → 叙事的经济基础不足。
3. **股市回升而居民消费/财富搬家未发生** → 传导链断裂，"锚"换不动。
4. **外部冲击下国家队撤退、放任下跌** → 是"有限度维稳"，非"规划做多"。
5. **多年后被证明关键产业与资本市场改革半途而废** → 草台论胜出。

## 四、时间窗与观察点（2025–2027）
- 居民存款搬家幅度 / 公募与 ETF 规模 / 新增开户结构。
- 社保、保险权益配置比例的变化。
- 央企分红率、市值管理考核的实际执行结果。
- 土地出让金 vs 国有资本经营预算收入：**缺口收敛还是扩大**（这是"股权财政"命题的量化生死线）。
- 硬科技产业的实际全球竞争力（收入、出口结构、专利/标准），而非仅市值。

## 五、分层结论（本推演最终立场）
| 层次 | 判断 | 置信 |
| --- | --- | --- |
| 意图层：有连贯的产业升级与资本市场布局意图 | 成立 | 较高 |
| 机制层：股票能承担"货币锚" | 不成立，只承担储值与融资功能 | 低 |
| 机制层：房地产是信用发动机而非蓄水池 | 成立 | 中高 |
| 结果层：本轮必成长牛 | 不可判定 | 低 |
| 元层："一切早已规划"这一叙事可证伪吗 | 若不写指标则不可证伪 | — |
