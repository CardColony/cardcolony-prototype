CardColony — Brand Spec v1

The mark is a C-shaped agent: the letter C with a visor band — two eyes in its hollow, an antenna on top. Two colors only: line color (C stroke · antenna stem · ard) and point color (eyes · antenna bead · Colony). The three point-colored elements always match.

1 · Anatomy

Master grid 240 × 240. Stroke 26 with round caps; eye radius 11, eye centres at (102,112) and (142,112) — 40 apart; antenna stem from y46 to y30, bead r7 at (120,24). The C body spans y48→192, so the antenna rises above cap height like a diacritic.

8 · Don'ts

Color
Don't tint the eyes, bead or Colony with UI semantic colors. The point color is brand-owned.
Lockup
Don't put a gap before ard, and don't build icon + full name. Pick one lockup; symbol-as-C is primary.
Form
Don't outline, shadow, gradient, box or rotate the mark. Don't crop or shorten the antenna.
Ground
Don't use the light state on dark grounds or the dark state on light. Don't set the mark on amber-tinted fills.
Stretch
Don't scale non-uniformly or rebuild the mark with a different stroke weight — only the -sm variant differs.
Size
Don't ship the standard weight below 48 px, and don't go below 16 px.
