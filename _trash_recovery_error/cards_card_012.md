# 10 距离目标缺什么

## 依赖链（有方向，非并列清单）
```
需求装置 → 才敢净减持 → 才有现金流 → 才叫"财政"
抵押品化 → 才有杠杆 → 才有规模
内容物（全球利润池） → 决定二十年上限
```

## 缺一：需求装置（唯一活结）＝M8
- 地产的"必需"是物理的（要住）；股权没有。必须人工造一个**国家自己也拆不动的**持有理由。
- 最可能路径：自动加入的个人养老金（美国 401(k) 类比）——用税优把居民储蓄系统性转为权益。
- **它成，下游全通；它不成，R6 永不启动，X0 永不触发。**
- 备注：养老默认通道是唯一一种"国家拆它＝自断第三支柱"的装置，故必须走这条路，而非再赌一次 2015 式赚钱效应。

## 缺二：抵押品化（只开半扇门）＝M7
- 央行已认（SFISF / 再贷款）；银行未认。
- 真正的大解锁：商业银行法 43 条"国家另有规定"的例外口子——**这是"杠杆端不必在百姓家"能否成立的法律前提**。
- 不开：只能继续在居民两融里打转（2015 已炸）。
- 风险：开了以后若重演 2018 股权质押爆雷，此路径宣告失败。

## 缺三：内容物（向量被修正）
- **短期市值可脱离利润**（流动性+预期+托底；纳斯达克为证）。
- 但纳斯达克高**不是因美国人口少**，是因美国公司拿到**全球利润池**（软件/芯片/云）。要复制的是"拿到全球利润"，不是换估值口径。
- 长期（10–20 年）市值必回归利润池；强制买入者若长期亏损，装置会在政治上爆掉。
- 最硬的一块是空的：华为不上 A 股。

## 一句话
**供给侧里程碑基本走完，需求侧一个都没走完；而"财政"二字住在需求侧。**三者缺一，这套东西就停在"国家扛着一个大仓位"。
