> 前置：工具线收拢（`4e2b2fd`）+ 收拢后清理已施工完毕。本任务书在**收拢+清理后的账本上**继续施工（`ToolDef` 六字段：schema/handler/readonly/switch/domain/status，`TOOL_REGISTRY` 19 件字面量）。

## 一、背景（为什么做）

通用 agent 缺四类基础工具：**bash**（终端执行）、**代码执行**（python）、**文件搜索补强**（正则 + 按文件名 glob）、**文件管理**（删/移/改名）。现状全项目零 bash/shell 工具、文件工具只有「建/覆盖/读/列」没有「删/移/改」、搜索只有关键词没有正则/glob。本任务书补上。

## 二、用户裁定条目（不可改，违反即作废）

1. **只管工具本身**：实现、注册、下发、执行。
2. **权限开关 / 安全边界 / 默认关门 = 权限线的活**。本任务书**不碰** `src/permissions/policy.py`、`config/permissions.json`，不设计「谁授哪个开关」「bash 的 cwd 边界」「命令白名单」。工具注册后，开关「接线 + 授给谁」由权限线做。
3. **工具自身健壮性**（超时、输出截断、编码兜底）属工具本身，本任务书做。
4. 「零闸」铁律只管**模型调用**；执行器的超时是**代码健壮性**（防子进程死循环挂死服务），不违反零闸。

## 三、共享执行器（bash / python 共用）

新建 `async def _run_subprocess(argv=None, shell_cmd=None, cwd=BASE_DIR, timeout=120.0) -> dict`（放 card_tools.py 内或独立 `exec_runner.py`，以不引入 import 环为准）。行为契约：

1. 异步执行：`asyncio.create_subprocess_shell`（bash）/ `create_subprocess_exec`（python 走 `sys.executable`），`stdout=stderr=PIPE`。参考 `src/storage/git_auto_commit.py`。
2. 超时：`asyncio.wait_for(proc.communicate(), timeout)`，`TimeoutError` → `proc.kill()` → `err("locked", "执行超时（>120s）")`。
3. 编码：`decode("utf-8", errors="replace")`。
4. 截断：stdout、stderr 各截到 **50KB**（51200 字节），超限末尾追加 `\n…（输出已截断，共 N 字节）` 并置 `truncated=True`。
5. **命令失败不是错误**：`exit_code != 0` 是正常返回（模型自判）；只有「起不了子进程 / 超时」才是 error 信封。
6. 返回：成功 `{"exit_code", "stdout", "stderr", "truncated"}`；异常 `err(code, message)`。

## 四、六件工具逐件定义

**handler 签名统一**：`async def _h_xxx(work_id, current_id, arguments, cards) -> dict`（与现有 19 件同款）。返回 dict 或 `err(code, message)`。

**关键裁定：本任务书 handler 内不写 `policy.check` 关口** —— 因为 bash/python 的开关（exec）还没进 `policy.SWITCHES`，写了也判不了。工具面「未授权不下发」由 §五 的开关占位 + `_filter_by_category` 保证；执行层关口属权限线接线时一并补（Open Item 注明）。

### 1. `bash`（终端执行）

- schema：`command` 必填（字符串）。description 说明「命令失败非错误、超时 >120s 报错」。
- handler：取 `command`（空 → `err("validation","command 不能为空")`）；`_run_subprocess(shell_cmd=command)` 透传返回值。
- `readonly=False`，`switch="exec"`（占位，见 §五），`domain=DOMAIN_EXEC`。

### 2. `python`（代码执行）

- schema：`code` 必填（字符串，多行直接写）。
- handler：取 `code`（空 → validation）；写系统临时 `.py`（`tempfile.NamedTemporaryFile(suffix=".py", delete=False)`，utf-8）→ `_run_subprocess(argv=[sys.executable, tmp_path])` → `finally` 删临时文件。写临时文件而非 `python -c`，规避 Windows 命令行多行引号/换行坑。
- `readonly=False`，`switch="exec"`，`domain=DOMAIN_EXEC`。

### 3. `search_files` 加 `pattern`（正则，改现有）

- schema 增 `pattern`（字符串，可选）：`{"type":"string","description":"正则表达式；非空时按正则匹配每行（忽略大小写），与 keyword 二选一，pattern 优先"}`；`required` 从 `["keyword"]` 改为 `[]`。
- handler：`keyword` 与 `pattern` 都空 → `err("validation","keyword 与 pattern 至少给一个")`；`pattern` 非空 → `re.compile(pattern, re.IGNORECASE)`（编译异常 → `err("validation", f"正则非法: {e}")`）逐行 `re.search`；否则沿用 `kw_lower in line.lower()`。其余（剪枝、凭证排除、200/2MB/20000 上限）逐字不变。

### 4. `glob_files`（按文件名找，新增）

- schema：`pattern` 必填，`path` 可选（起始目录，缺省项目根）。
- handler：`Path(path or BASE_DIR)`；pattern 含 `**` → `Path.rglob`，否则 `Path.glob`；只收 `is_file()`，跳过 `file_tools._is_pruned` 与 `_credential_excluded`；上限 200 条，超出置 `truncated=True`；返回 `{"pattern","scope","matches":[相对路径],"truncated"}`。
- `readonly=True`，`switch=policy.SWITCH_TOOLS_FILE`，`domain=DOMAIN_FILE`。

### 5. 文件管理三件（新增）

- `delete_file(path)`：`file_tools._resolve` 越界校验；是目录 → `err("validation","这是目录不是文件")`；不存在 → `err("not_found",...)`；`Path.unlink()`。`readonly=False`。
- `move_file(src, dst)`：两路径都过 `_resolve`；`src` 不存在 → not_found；`shutil.move`；返回新路径。`readonly=False`。
- `rename_file(path, new_name)`：`path` 过 `_resolve`；`new_name` 含路径分隔符 → `err("validation","new_name 只能是文件名")`；同目录 `Path.rename`；返回新路径。`readonly=False`。
- 三件 `switch=policy.SWITCH_TOOLS_FILE`，`domain=DOMAIN_FILE`。

## 五、权限接线（本任务书的落法）

- **不碰** `policy.py` / `permissions.json`，不新增开关常量。
- bash / python 的 `switch` 写**裸字符串 `"exec"`**（占位：`policy.SWITCHES` 暂无此开关，故 `has_perm` 恒 False → 这两件**默认关门、永不下发**，待权限线加 `SWITCH_EXEC` 常量后改为引用常量、自然生效）。
- glob_files / 文件管理三件的 `switch` 用现有常量 `policy.SWITCH_TOOLS_FILE`（已接线，授 tools_file 的卡可见）。
- **说明书渲染同步处理**：`build_tool_manual()` 渲染时**跳过 `switch` 不在 `policy.SWITCHES` 里的工具**（即未接线的占位工具）。这样说明书不出现 bash/python（因为其 switch="exec" 非法），与工具面「不下发」一致——收拢「说明书＝工具面投影」不破。
