## 首页两态判定逻辑（GET / 入口）

```
读取 localStorage nav.recent.v1（上次停留的卡）
├─ 有 → 302 跳 /work/{wid}#{cid}（上次对话页）
├─ 无但有项目 → 302 跳最近活跃 work 的对话页（activity 现算，/api/works 首项）
└─ 全新无任何项目 → 200 渲染空态首页（home.html）
```
