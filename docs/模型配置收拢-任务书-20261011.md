## 目标结构（新 config/models.yaml）

```yaml
providers:            # 供应商父层（端点+密钥去重只存一次）
  nous:     { protocol: openai,   base_url: ..., api_key_env: NOUS_API_KEY }
  deepseek: { protocol: deepseek, api_key_env: DEEPSEEK_API_KEY }
  zhipu:    { protocol: openai,   base_url: ..., api_key_env: ZHIPU_CODING_API_KEY }
  minimax:  { protocol: openai,   base_url: ..., api_key_env: MINIMAX_API_KEY }
  aliyun:   { protocol: openai,   base_url: ..., api_key_env: ALIYUN_TOKEN_PLAN_API_KEY }
  opencode: { protocol: openai,   base_url: ..., api_key_env: OPENCODE_API_KEY, extra_headers: {...} }

models:               # 模型子层（纯模型无角色语义）
  haiku:          { provider: nous,     model: anthropic/claude-haiku-5.5, temperature: 0.3, thinking: auto }
  deepseek-pro:   { provider: deepseek, model: deepseek-v4-pro,            temperature: 0.3 }
  glm-flash:      { provider: zhipu,    model: glm-5.3-flash,              temperature: 0.3 }
  minimax-m3:     { provider: minimax,  model: MiniMax-M3,                 temperature: 0.7, thinking: off }
  qwen-max:       { provider: aliyun,   model: qwen3.8-max,                temperature: 0.7, thinking: off }
  glm-5.3:        { provider: zhipu,    model: glm-5.3,                    temperature: 0.7, thinking: auto }
  deepseek-flash: { provider: opencode, model: deepseek-v4.1-flash,        temperature: 0.7 }  # 未启用

bindings:             # 角色→模型（key 全部来自 roles.json，不手写角色）
  execute:    haiku
  think:      haiku
  synthesize: haiku
  condense:   glm-flash
  compress:   haiku
  draft:      haiku
  viewpoint:  [minimax-m3, qwen-max, glm-5.3]

system:
  fallback_model: deepseek-pro

simple:
  enabled: true
```

**术语定死**：`provider` = 供应商名（nous/deepseek…）；`protocol` = litellm 协议名（openai/deepseek…）。编译层做 `protocol → litellm provider 前缀`，翻译只此一处、单向。

**`context_window` 是死字段，明写移除**（后端零读取、前端零处）。

## 编译层规则（gateway 一行不碰的关键）
gateway 吃平铺字典：`self.config["models"][model_name]`、`self.config["models"]["fallback"]`（硬编码降级锚点）、`self.config["retry_grading"]`。编译层：

1. **provider 展开**：每个模型把 `provider:` 指向供应商的 `protocol/base_url/api_key_env/extra_headers` 继承合并进来，`protocol` 落为 litellm 的 `provider` 字段。
2. **thinking 方言翻译**：
   - minimax-m3 `off` → `extra_body.thinking.type=disabled`
   - qwen-max `off` → `extra_body.enable_thinking=false`（`on` → `true`）
   - glm-5.3 / haiku / 其它 → 不传思考参数（端点自然行为）
3. **fallback 复制**：把 `system.fallback_model`（deepseek-pro）的完整展开结果**额外复制一份**成 `config["models"]["fallback"]`，原 key 保留，两个 key 并存、内容相同。
4. **simple 透传**：`enabled` 原样；`retry_grading` 段保留现状（关闭）。
