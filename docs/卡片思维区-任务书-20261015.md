## 四、语义（保持不变，只做实现）

- **类型清单的唯一来源＝`config/card_type_registry.json`**。本任务的配置文件**不复制**它。
- **「没有来源就不出现」**：该类型在该维度没有文本 ⇒ 该区不出现，**不报错、不算漏配**。
- **配置是控制源，不是可用性依赖**：读不到/坏 JSON ⇒ 视为全空，**绝不阻断装配**（fail-open）。
- **新增类型无需任何声明**：它在所有维度里天然存在（没写＝空）。
