## 7. 发现的问题清单（按严重度）

1. **【功能/技术，须改】R13 用硬编码 200ms 自设定时器做单击折叠判定**（与正稿「不与自设定时器混用、该值不得短于系统双击间隔设置」不符）。复现：对有子卡的卡，第一次点击后 >200ms 再点第二下（模拟慢双击）→ 200ms 时先触发折叠，第二下落在重建后的节点上，双击开对话失效/画面误折叠。内置自测用即时合成双击，掩盖此场景。
