## 4. 三验（Task5 硬要求）

### 4.1 验一：进程身份

```powershell

  Select-Object ProcessId, ExecutablePath, CommandLine
Get-Content .server.pid
```

**判据**：对外服务的 PID == `.server.pid` 内容 == 期望解释器路径。
**本仓实测存在 4 个 `main.py` 进程横跨 2 个副本**，重启前必须先对上号，
否则停错进程＝停错环境。

### 4.2 验二：pyc 重编

```powershell
Get-ChildItem -Recurse -Path src -Filter *.pyc |
  Where-Object { $_.LastWriteTime -lt (Get-Date).AddMinutes(-5) } |
  Measure-Object
```

**判据**：重启后**旧 pyc 数为 0**。同目录同秒级 mtime 变化可能命中缓存解释器，
必要时先删 `src\**\__pycache__` 再启动。

重启与一次完整对话之后重取：
