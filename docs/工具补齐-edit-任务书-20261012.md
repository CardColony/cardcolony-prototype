# 工具补齐 · edit_file 精准编辑 · 工程任务书（2026-10-12）

> 派工性质：**施工任务书**。自给自足规格，外部 agent 照此执行，不得自由发挥。  
> 前置：工具线收拢 + 清理 + 能力补强已施工完毕（`TOOL_REGISTRY` 25 件，`ToolDef` 六字段）。本任务书在该账本上**新增一件工具** `edit_file`。

## 一、背景（为什么做）

编程 agent 的基础工具里，唯一缺的是「精准编辑」——现状 `write_file` 只能**整个文件覆盖写**，改一行代码也得「read 全文 → 复述全文 → 覆盖写全文」，token 爆炸、易误伤无关段落。补 `edit_file`（给 `old_string` 换 `new_string`，只改那一处），基础工具即闭环。

## 二、裁定条目（不可改）

1. `edit_file` 是**文件工具**，与 `write_file` **完全一致待遇**：开关、权限关口、备份、线程池卸载——全部照 `write_file` 的既有模式，不另立一套。
2. 权限「授给谁」仍归权限线（`permissions.json` 已配 `tools_file`），本任务书只声明 `edit_file` 归 `tools_file`，不碰 `policy.py` / `permissions.json`。

## 三、工具定义

### schema

```json
{
  "name": "edit_file",
  "description": "精准编辑文件：把文件中的 old_string 替换为 new_string（只改那一处）。old_string 必须在文件中恰好出现一次，否则报错，不会做任何修改。",
  "parameters": {
    "type": "object",
    "properties": {
      "path": {"type": "string", "description": "文件路径（相对 D:\\AI_station 或绝对）"},
      "old_string": {"type": "string", "description": "要替换的原文（须与文件内容逐字匹配，含缩进与换行）"},
      "new_string": {"type": "string", "description": "替换后的新内容"}
    },
    "required": ["path", "old_string", "new_string"]
  }
}
```

### 实现（`file_tools.edit_file(path, old_string, new_string)`，同步 def）

1. `path` 过 `_resolve` 越界校验（与 read_file/write_file 同）。
2. 读文件全文 `read_bytes` + `decode("utf-8")`；二进制 / 凭证文件拒（复用 `_credential_excluded` 判据，与 read_file 同）。
3. **匹配计数**：`text.count(old_string)`：
   - `0` → `{"error": "old_string 未在文件中找到"}`（not_found 语义）；
   - `>1` → `{"error": "old_string 出现 N 次，请提供更精确的上下文以唯一定位"}`（validation 语义）；
   - `1` → 替换（`text.replace(old_string, new_string, 1)`）。
4. 覆盖前备份：**复用 `write_file` 的备份代码**（`_backups/{相对路径}/{时间戳}`，先读原文备份、备份失败即中止不写）。
5. 写回 `target.write_bytes(...)`；返回 `{"ok": True, "path": 相对路径, "replacements": 1, "backup": 备份路径}`。

### handler（`card_tools._h_edit_file`，async，与 `_h_write_file` 同构）

```python
async def _h_edit_file(work_id, current_id, arguments, cards):
    if not file_tools.check_file_access(arguments.get("path", ""), cards.get(current_id)):
        return err("denied", f"越权：无权访问 {arguments.get('path', '')}")
    return await asyncio.to_thread(
        file_tools.edit_file,
        arguments.get("path", ""),
        arguments.get("old_string", ""),
        arguments.get("new_string", ""),
    )
```

1. `TOOL_REGISTRY` 新增 `edit_file` 键（共 26 件）。

8. `build_tool_manual()` 含 `- edit_file(`（switch 合法，不跳过）。
