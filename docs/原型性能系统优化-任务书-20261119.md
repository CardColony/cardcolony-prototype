# 原型性能系统优化任务书

施工对象是 `D:\AI_station\推演agent` 原型。按转发、大卡读取、上下文装配三批交付，执行 Agent 负责实现和取证，外部验收按原始读数复跑。先读 [优化方案](原型性能系统优化-方案-20261119.md) 和 [项目规则](../AGENTS.md)。保留当前工作树的其他施工改动。验证用隔离服务实例、测试工作及受控模型替身。5700 服务进程的重启或停止须由用户另行明确同意。

## 基线与测量

1. 记录代码基线、相关未提交改动、运行形态、runner 数量、数据规模和测量脚本。在隔离环境记录每条端点的原始时间和结果，时间拆成代理、runner 执行和前端可用三个层次，按实际能采到的层次留证。
2. 采用相同输入做改前改后对照。包含空闲、小卡、多卡运行、有持续追加的大卡、一个 runner 变慢或失联、有 SSE 常驻等场景。并发与事件持续时间按当前原型实况选择，两次运行使用同一配置。
3. 区分浏览器到 web 与 web 到 runner 的日志行。按入口、状态码和负载状态报告样本数、P50、P95、最大耗时和错误数。超时保留在结果里。补充首包、完整响应、响应字节和可取得的内存峰值。隔离探针的读数与生产访问日志分别陈述。

## 第一批 转发

**实现。** 盘点 `_forward`、`_fanin_get_merge`、`_fanin_sse_stream`、`forward_ctl` 及其入口。为每个需要共用 HTTP 连接的事件循环管理该循环自己的客户端，明确短请求与长流的容量、释放及关闭顺序。先完成连接复用，再判断导航轮询是否仍产生重复压力。简单性能改动使用既有路由和合并逻辑。

**验收。**

- 对同一路径连续执行读、汇总和控制请求，证明客户端创建次数与进程、循环和用途有关，连续请求稳定复用。对比每次建客户端与复用连接的整条回环汇总耗时，日志能拆出建立连接与等待 runner。
- 用 web 入口实际访问导航运行集、卡片时序、会话标签和进度。核对返回状态、查询参数、目标分片和响应数据。复测中位和尾延迟，记录连接复用带来的改善。
- 让不同 runner 同时推流并保留慢订阅客户端。验证短查询仍能响应，正常流顺序、心跳、退出、重连和资源释放成立。长时间静默的正常模型回合继续按现有规则完成。
- 分别模拟慢 runner、部分不可达、全部不可达以及对端非 2xx。检查原有错误语义，记录每片结果与总等待时间。控制请求超时或回包丢失时核对真实执行状态，避免重复派发可能已在运行的操作。

## 第二批 时序与卡片读取

**实现。** 从时序和标签的查询链复跑，拆出取卡、撤销扫描、读页、载荷裁剪和编码耗时。把撤销区间读取改为可重建的增量读侧数据。沿用原文事件日志及有界缓存。将会话标签列表、会话解析与存在性检查收口到适合各自需求的窄读取。

**验收。**

- 在有乱序写入、撤销和新 run 的固定原文上，对比改前改后的首屏尾窗、向上翻页和增量。逐项核对事件标识、可见集合、排序、游标、`has_earlier`、工具结果裁剪及不同会话的隔离。
- 用原文文件和持续追加的隔离大卡，记录每次查询触及的历史字节量。在已经扫完的原文后追加普通事件或撤销事件，撤销区间读侧只扫描新增的完整记录。文件替换、截短、并发追加和半行时能安全恢复，撤销项不会重新出现。
- 复跑不存在的卡、无效会话、主会话与附加会话。会话标签和存在性检查的查询只需要相应的卡片标识和会话数据，无卡面正文及完整历史的处理成本。完整卡详情和卡片权限结果照原契约核对。
- 报告小卡与大卡的冷读、重复读、追加后读和翻旧页。记录实际文件规模、读取范围和响应大小。比较持续工具输出时打开卡片的可用时间和峰值内存。

定位文件见 [事件原文与分页](../src/storage/event_log.py) · [时序和会话入口](../src/api/routes.py) · [卡片查询](../src/storage/card_store.py) · [载荷投影](../src/api/payload_cap.py)。

## 第三批 上下文装配

**实现。** 先在同一轮观测中区分排队、读存储、分区生成、序列化、提供方首事件及用户首字。采样复核超长卡、普通卡、工具续跳与席位。根据分段读数去掉重复取数或渲染，优先复用同回合的已知稳定结果。有跨轮复用时，给出有效范围和数据失效来源。

**验收。**

- 固定同一输入、身份、能力和事实快照，用可控模型捕获网关的最终消息、角色顺序、工具 schema、调用与结果配对。核对主模型、席位和工具续跳的语义及当前轮提示。
- 用相邻两轮修改卡面、线、记忆水位或会话身份，验证模型立即收到该轮应有的变化，缓存无跨会话串用。
- 分别交付装配耗时、序列化耗时、请求字节、提供方等待与缓存读数。标清哪些字段由提供方报告，哪些由原型自己测量。没有可比的模型端样本时，先交本地耗时与语义核对。
- 复跑工具调用与回执专项。真实超长会话里的工具表现纳入使用观察，相关内容见 [工具调用任务书](工具调用与真实回执-任务书-20261119.md)。

定位文件见 [装配取数](../src/api/context_assembler.py) · [分区投影](../src/api/context_regions.py) · [工具续跳轮槽](../src/api/tool_fold.py) · [网关发送](../src/model_gateway/gateway.py)。
