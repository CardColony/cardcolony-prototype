## 二、已完成（P1 视觉 / P2 交互 / P3 细节）

### P1 视觉体系
- 新增 `static/canvas.css`：画布专属设计系统，只在 `.page-canvas` 作用域生效
  （表面 4 级 / 文本 3 级 / 语义 4 色 / 类型 6 色 / 4pt 节奏 / 圆角 4 档 / 阴影 3 级 / 动效 2 档）。
- 卡面重排四层：类型行（色点＋类型名＋状态徽标）→ 标题 → 摘要（底部渐变淡出）→ 底栏（子卡徽章＋相对时间）。
- 父子线：直角折线 → **三次贝塞尔**；端点圆点 → **marker 复用**（232 条边省 464 个 SVG 元素）。
- 工具栏图标化（适配 / 搜索 / 整理 / 规则面板），主按钮保留文字。
- 空态、骨架屏、右键菜单、命令面板、小地图、多选操作条的视觉全部走同一套 token。
- **修掉一个既有缺陷**：`#world` 尺寸为 0，而 CSS 给内部 SVG 设了 `width:100%`，
  SVG 实际是 0×0 —— 连线在 DOM 里一直存在、屏幕上一直看不见。
