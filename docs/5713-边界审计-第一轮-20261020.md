## 三、主题二：模块之间私下互相依赖

### M1 运行时没有分层：51 模块一个环（P0）

C4 产出（JSON 里 `scc_runtime`）：**唯一一个强连通分量，51 个模块**，横跨
`api / goal / permissions / storage / thinkchain / toolcard` 全部六个包；包级同样全互达
（`scc_package_runtime = [toolcard, thinkchain, storage, permissions, goal, api, (root)]`）。

包级依赖矩阵（src 内，n＝语句数）：

```

thinkchain -> storage 8 | api 1 | permissions 1
goal       -> storage 6 | api 4 | permissions 1
```

**判定**：不存在任何一对包是单向依赖。任何「下层不许调上层」的规则，在代码里**一条都不成立**。

## 四、处置优先序

排序依据：① 会不会**造成越界/数据落到别人树里**（正确性）＞ ② 会不会**让改造必然漏改**（结构性）
＞ ③ 会不会**让下一次改动炸在启动**（风险）＞ ④ 只是可读性。

### P0-1 文件工具根：`file_tools.BASE_DIR` 与 `BACKUP_DIR` 立即止血（H1/H2）

- **改什么**：`BASE_DIR` 改由注入提供（缺省＝仓库根 `Path(__file__).resolve().parents[2]`）；
  `ALLOWED_ROOTS` 缺省＝**本实例根**；`BACKUP_DIR` 改到**实例根下** `_backups`。
- **为什么第一**：它是唯一能把数据/备份写进 5700 目录树的通道，且**当前正在发生**（H2 实测）。
- **验收判据**：从 5713 import 后 `ALLOWED_ROOTS` 不含主仓路径；在 5713 写一个文件，备份出现在
  `.worktrees\5713\_backups\`，主仓 `_backups` 无新增（按 mtime 比）。
- **波及**：`tests/conftest.py:74-80`（已按注入设想写，改后三条 monkeypatch 可退）；
  `scripts/{run_test_instance_5701:85-89,run_canvas_5707:64-66,s4_compare_snapshot:56-59,
  s5_crash_drill:60-63,preflight_shadow_offline:33-36}` 的改写行随之退休。

### P0-2 建「单一 paths 注入点」（H3/H4/M4 的根）

- **改什么**：新增 `src/paths.py`（**唯一**求值点）一次算出 `REPO_ROOT / WORKS_DIR / LOGS_DIR /
  SNAPSHOT_ROOT / BACKUP_DIR / ALLOWED_ROOTS / CONFIG_DIR`；13 处 `BASE_DIR = parents[2]` 改为引用它；
  `SNAPSHOT_ROOT` 改显式配置（环境变量 `ECO_DATA_ROOT` 优先），**不再用目录名派生**。
- **为什么**：H1/H4/M4 都是它的症状；不建它，H1 的修法会在下个模块里复现。
- **验收判据**：`C2_root_constants` 从 46 降到 ≤10 且 `kind=abs` 归零；`C3_cross_module_writes` 从 42 降到 ≤5。
- **波及**：13 个 src 模块 + 7 个启动脚本；`tests/conftest.py` 由 monkeypatch 改注入。

### P0-3 拆导入期环（M2）

- **改什么**（四条顶层边，均不改语义）：①`permissions/policy.py:36` 的 `prompt_log` 改函数内取（或把
  `append_perm_log` 抽到 `src/infra/`）；②`thinkchain/model_pick.py:15` 的 `model_config` 改延迟；
  ③`thinkchain/plan_tools.py:35` 的 `policy` 改延迟；④`api/settings_api.py:50` 的 `roles` 把常量表下沉到
  `src/infra/roles_table.py` 即可断。
- **为什么在 P0 而不是 P1**：它决定**下一步任何重构会不会变成启动期 ImportError**；成本 4 行，收益是解除封印。
- **验收判据**：`scc_package_import_time` 从 `[[thinkchain, permissions, api, (root)]]` 变为 `[]`。
- **注意**：**不动** `card_store → api` 的延迟反调（那是 P1-4 的活），只拆**顶层**边。

### P1-4 storage 写路径反向调用改事件注册（M3）

- **改什么**：把 `card_store.py:810/1010/1016/1231` 四处反向 import 收进 `src/storage/hooks.py`
