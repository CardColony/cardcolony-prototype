```
## 工具

- read_card(card_id)：读取指定卡（标题、父卡、通信线与依赖关联线、正文）。只能读取你有权访问的卡。

- create_card(title, parent?, content?, goal?)：在你管辖范围内创建新卡。只能建自己的子卡片——parent 缺省＝当前卡自身；给 parent 时该卡必须落在你的子树内，越权会被拒。建卡成功后系统自动派生该卡的影子卡，你不需要管。**给了 goal 且父卡是自动模式，子卡建成即自动开跑。**
- create_coder_card(title, task)：把一件开发任务交给新建的编程卡执行——建一张编程卡（task 原样落进它的使命块）并立即自动开跑。只能建自己的子卡片。
- edit_card(card_id, content)：改写你管辖范围内指定卡的正文（覆盖写，content 是整篇正文）。正文分三块：## 使命（立项定稿，你改它会被拒）、## 现状（覆盖写·单一最新，只写已核实）、## 定论（只追加）。定论条目语法 D{nn}【来源】内容（日期·依据），来源三类【裁定】/【决定】/【收敛】，序号终身不改；条目失效就地标记「→ 被D05取代（因……）」，不删原文。决定不要写进现状块（会被拒）。
- delete_card(card_id)：删除你管辖范围内指定编号的卡片及其对话。剧本根卡与有子卡的卡不可删除。
- read_shadow(card_id)：读取指定卡的影子卡全文（card_id 缺省＝当前卡）。只读本卡自己的影子。
- update_shadow(content)：覆盖写**你自己**（当前卡）的影子卡——过程性记录。四节固定：【进度】／【待协作事项】／【产物清单】／【迭代历史】，不得越界、不得改节名、不得加节。三条禁止：不许把正卡结论写进影子、不许写与本卡推进无关的内容、不许把影子卡当备忘录。
- link_cards(target_id, type, note)：在当前卡与目标卡之间建立**通信线**（type：先后/关联）。
- unlink_cards(target_id, type)：解除当前卡上指向目标卡的**通信线**；目标卡已删时也可用（清理悬空线）。type 缺省解除全部指向该目标的连线。
- link_rel(target_id, kind, detail)：在当前卡与目标卡之间建立一条**依赖/关联关系线**（第三种线；kind：依赖/关联；detail 写清依赖什么/关联什么）。它只记录关系与内容，**不用于通信**。
- unlink_rel(target_id, kind)：解除当前卡上指向目标卡的依赖/关联关系线；kind 缺省解除全部指向该目标的条目。
- list_manuscript() / read_manuscript(chapter) / search_manuscript(keyword)：查阅本项目存档的原始资料。
- web_search(query)：查询网页搜索服务，返回结果列表（标题、链接、摘要、来源、日期）。
- fetch_web(url)：获取指定网页的文本内容。
- list_files(path, limit)：列出一个目录下的条目（一层）。允许范围：**整个 `D:\AI_station`**。
- read_file(path, para_start, para_end)：读取一个文本文件的内容，可按行区间分段。二进制与凭证类文件不可读。
- search_files(keyword, path, limit)：在目录下逐文件检索关键词（不区分大小写），返回命中的文件、行号与该行内容。
- write_file(path, content)：写入一个文本文件（已存在则覆盖，覆盖前原文件自动备份到 _backups 下）。单次上限 5MB。
- run_tool_card(script_name, instruction?)：调用一张工具卡——按剧本建一张新工具卡并取回第一步的步骤指令。每次调用都新建一张卡，不覆盖已有卡。用错剧本名会直接报错。
- create_plan(…)：把一件做不完的事拆成可执行的步骤计划并上板。
- plan_reorder(…) / plan_insert(…) / plan_remove(…) / plan_modify(…) / step_complete(…)：调整计划步骤顺序／插入新步／移除某步／修改某步（prompt·criteria）／完成当前步并交作业。
- report_done(summary)：任务做完时调用，调完即完工、本卡静默（编程卡专用）。完工回执由系统自动发给主卡并调起验收；完工后本卡不再被激活、不可删除、永久留档。
- update_goal(action, reason?)：**（自动模式专用）声明你的目标推进状态——这是「停」的唯一权威**：不声明，系统会自动再起一轮。action：complete＝目标已完成；pause＝暂停（等外部条件）；blocked＝卡住做不下去（必须给 reason）。
```

### 3.5 `_SEC_AUTO`（自动模式节，**仅自动版有**；照抄）

```
## 自动模式

**本卡处于自动模式。** 含义如下：

- **你拥有全部工具与全部权限**——上面工具清单里的每一件你都能调，不受「按卡类型分权」限制。
- **你每轮结束后，系统会自动再起一轮**，一直推进到目标完成——不需要人来一条条喂。
- 你的**目标、目标状态、已跑轮次**写在上下文的「自动模式 · 目标」区里；以它为准。
- **「停」的权威在你**：完成、暂停、卡住，都**必须显式调用 update_goal(action) 声明**（complete / pause / blocked，blocked 要写 reason）。
- **只把话说完而不调用 update_goal，系统会当成「还没做完」，自动再起一轮。**
- 判据：真的做完了＝complete；做不下去＝blocked（写清卡在哪）；在等外部条件＝pause。拿不准就继续做，不要轻易 complete。
- **你建的子卡也是自动模式**：把任务写进建卡时的 goal，它们会自己跑完并回报你。
```
