# 研究项目词表与存量迁移 · 任务书 v1

- 立项卡：card_041 卡片类型
- 前置：卡片分类基座 T1–T7 已完成（见《卡片分类基座_任务书v1.md》执行报告）
- 用户裁定（2026-10-08）：研究项目下的子卡统一叫 **课题卡**
- 性质：配置扩展 + 存量迁移，**不改写路径代码逻辑**（三闸已就位，只动注册表与数据）

## 一、目标

1. 研究项目（research_project）词表立项：L1 仅一种卡——课题卡（topic）。
2. 存量迁移：work_001（22 张"线索"）、work_003（13 张"线索"）共 35 张 → 课题卡。
3. 迁移完成后，全局收紧：legacy 类型（剧本/线索等六值）write_blocked 置 true，老类型正式退役。

## 二、词表定义（写入 config/card_type_registry.json）

| 项 | 值 |
|---|---|
| 类型码 | `topic` |
| 中文名 | 课题卡 |
| 所属 | research_project 的 l1_vocabularies |
| can_have_children | true（课题下可再挂子卡，与子项目卡同） |
| owner_card_id | 不需要（非工具卡） |
| 状态机 | 无（普通工作单元） |

同时把 `research_project` 的 `l1_vocabulary_ref` 从 null 改为指向本词表。

## 三、任务分解

### T1 注册表扩展（只改配置）

- 验收：预览输出 35 张待迁移清单，逐张列卡号

### T3 执行迁移（先备份后迁移）

### T4 legacy 全局退役（改配置，不改代码）
