## 复跑与重建命令

```powershell
$env:PYTHONPATH = 'tests'
# 批七计量+外部审计（发送边界接线 7 例）
python -m pytest tests/test_batch7_cost_accounting.py tests/_ext_b7_audit.py -q
# 批一至六专项（本轮全绿）
python -m pytest tests/test_batch2_scope.py tests/test_batch2_outbound.py `
  tests/test_batch3_review_phases.py tests/test_batch4_tool_evidence.py `
  tests/test_batch5_cost_coordination.py tests/test_batch6_memory_reuse.py -q
# 台账汇总（重复读同一份 JSONL 产出同一报表）
python -m src.infra.cost_ledger report <cost_ledger-*.jsonl>
python -m src.infra.cost_ledger diff <a.jsonl> <b.jsonl>
```

真实路由台账随 `observe.LOGS_DIR` 写入 `cost_ledger-*.jsonl`。`client.send` 前分配尝试编号，确认实发、断连、终帧和用量按该编号补记。鉴权等发送前失败以及业务收口使用独立事件编号，重复读取不会增加物理尝试数。

业务对照读取宿主核验的任务结果、汇报状态和工具执行事实。同一模型收口状态下，业务差异仍会显示。普通对话没有可机械核验的完成判据时，业务一致性记为未知。

后台写入者随文件保存检查点。`report` 与 `diff` 校验各写入者的行号覆盖、丢行和写失败。`complete=true` 覆盖已读文件中的检查点范围，`false` 表示已知残缺，`null` 表示旧账缺少完整性证据。残缺或未知的文件仍可查看绝对读数和观察差值，不能据此认定成本改善。
