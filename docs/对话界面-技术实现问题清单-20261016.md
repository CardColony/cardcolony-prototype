## A. 运行中的 15s 恢复轮询无条件重跑 —— **已处置**

当前 `workspace.js tryRecover` 已不是「无条件 resync」：

- 先 `GET /progress` 查后端是否仍在跑；
- **在跑、且事件流未断**（`EventFlow.streamDead` 为假）→ 直接返回，**什么都不做**；
- 只有「后端已不在跑」或「流已断」才回流结算。

代码注释自述：此前每 15s 无条件 resync 正是「前面信息突然全出现 / 历史搬位」「从头到尾算一遍」的来源，已收紧。
**结论：按当前代码不成立。**

## B. 事件流并存两套机制；生效的是「0.4s 轮询 + 全量复制」，pub/sub 是死码

- 一套完整 pub/sub（`event_stream.subscribe` / `subscribe_tokens` / `_fanout`，含「队列满丢最旧帧」）——**全库无生产调用方**（仅测试触碰）；
- `/stream`、`/tokens` 路由实际各自 `while True` 轮询 `journal_of(...)`，每 0.4s / 0.25s 一次；`journal_of` = `list(_journals[key])` **全量复制** → 每次轮询 O(N)，N＝该卡自进程启动以来的全部事件。

**依据**：`src/api/routes.py`（`stream_card_events` / `stream_card_tokens` 生成器）、`src/api/event_stream.py`（`journal_of` 全量复制；`subscribe` 无调用方）。
**影响**：随进程存活时间线性劣化。**置信度**：高（grep 可证）。后端本会话未变 ⇒ 结论不变。

## C. 内存 journal 无上限

`_journals` / `_token_journals` 只 append；`run_start` **不再清零**（A5 分段制）；原环形上限（300 / 5000）已删 ⇒ 每卡 journal 随进程存活单调增长。叠加 B 的 0.4s 全量复制 ⇒ 长跑进程 CPU/内存随事件量劣化。

**依据**：`src/api/event_stream.py`（`emit` / `emit_token` 的 append；无任何裁剪）。**置信度**：高。后端未变 ⇒ 结论不变。

## I. `lastSeq` 游标跨服务重启失效（风险上升）

`stream.js start()` 仍 `from = st.lastSeq > 0 ? st.lastSeq + 1 : 0`；而 `lastSeq` 取自**内存 journal seq**（进程内计数器，重启归零）。
且 `stop()` 现已改为**不清渲染状态**（只关流）⇒ `lastSeq` 在同一张卡的多次发送间**持续保留**（初版时 `stop()` 会清 `current` 从而重置游标）。
故：同一张卡第二次发送即走 `from>0`；若期间服务重启，新事件（seq 从小起）会被全部过滤 → 实时过程断供至刷新。
**置信度**：中（窗口窄：运行中/两次发送间重启）。**后端未变**。

## J.（新增）无条件滚底 —— 用户翻看历史时被拽到底

`stream.js` 的 `renderSnapshot`、`renderAffected`（实时每帧都走它）、以及逐字 `appendChunk` 路径**都调 `scrollBottom()`**；`workspace.js` 多处调 `scrollChatBottom()`。
后果：**只要本轮在跑（或任何重画发生），滚动条就被拽到底**——用户往上翻看历史时会被打断、弹回底部。
**依据**：`static/stream.js`（`renderSnapshot` / `renderAffected` / `appendChunk` 末尾的 `scrollBottom()`）、`static/workspace.js`（`scrollChatBottom` 调用点）。
**置信度**：高（调用点可 grep）。**注**：初版遗漏。

## K.（新增）`pullUserBubble` 全量拉取 + 逐条重画

`stream.js pullUserBubble` 最多循环 **6 次 × 500ms**，每次都 `GET /timeline`（**全量**该卡时序）；且对**每条** `user_message` 都 `applyRecord` + `renderAffected`（每命中一条即重画该组 + 滚底）。
**影响**：发送后 3 秒窗口内重复全量拉取；长卡下开销偏大。**置信度**：高。**注**：轻，初版遗漏。
