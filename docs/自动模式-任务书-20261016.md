## 一、背景（为什么做）

【用户】这是一次**实验**：把系统**完全放权给模型**（沙箱里），跑复杂任务，看它会不会犯错、
会不会越权，再据此收窄。

当前系统是**人驱动**的：你发一条 → 卡跑一轮 → 模型停 → 结束；要往下走必须你再发一条。
「自动模式」补的正是这一环：**让卡自己决定「还没完，继续」**，一直推进到任务完成。

参考实现：dsh（`D:/AI_station/deepseek-harness`）的 **goal 模式**——
在模型外面挂一个「轮次驱动器」，模型一停就自动起下一轮；「停」由模型显式声明。

13. **父卡让位**：父卡若有子卡目标未终止 ⇒ 父卡不起轮（两种模式都适用）。

### 块 3 · 驱动器 ＋ 执行闸（本任务核心）

**任务**

- `src/api/auto_driver.py`（新建）：
  - `after_turn(work_id, card_id)`：读卡 meta → 判 `auto_mode` / `goal_state=="active"` / 有 `goal` /
    **无未终止子卡**（父卡让位）→ `goal_rounds += 1` → 起下一轮
    （复用 `message_runner._spawn_tracked` ＋ `append_user=False`）。
  - `kick(work_id, card_id)`：目标设定后点火（建卡即起跑 / 用户首条消息）。
- `src/api/serial_gate.py`（新建）：
  - 每 work 一把执行锁；串行模式下起回合前 `acquire`，**拿不到则排队**（await，非 409）。
  - 锁的**持有期＝一张卡的整个目标生命周期**（起跑 → 目标终止），保证「一张子卡跑完再下一张」。
  - 并行模式＝不启用（直接放行）。
  - 配置读取：执行模式（serial / parallel）。
- `routes.py`：
  - `_run_message` 结构改为「取结果 → `finally` 释放互斥体 → **再调 `auto_driver.after_turn`** → 返回」。
  - 起回合前经 `serial_gate`（串行模式）。
- `control.py`：停止扩为**三件**——①停当前轮（现有）②**关自动继续**（`goal_state→paused`）
  ③**级联停自动子卡**。

**硬判据**

1. **自主跑**：auto 卡目标 active 时，一轮结束**自动起下一轮**；模型声明完成 ⇒ **停**。
2. **不空转**：父卡有未终止子卡时**不起轮**；子卡全终止后恢复。
3. **串行真串**：串行模式下建 N 张子卡 ⇒ 任一时刻执行锁**只被一张卡持有**（可断言）；
   一张子卡目标终止后才轮到下一张；**拿不到锁是排队，不是 409**。
4. **并行真并**：并行模式下 N 张子卡可同时跑。
5. **停得住**：按停止 ⇒ 不再起新轮 ＋ 子卡也停 ＋ **执行锁释放**（队列不饿死）。
6. **接线位置**：驱动器调用**在互斥体释放之后**（可用「连续两轮不被 409 拒」断言）。

**交付**：`auto_driver.py` ＋ `serial_gate.py` ＋ `routes.py` ＋ `control.py` ＋ 配置 ＋ 测试。

## 七、验收（最终关门）

1. **自主跑**：一张 auto 卡领到任务后，无人干预下连续跑多轮，直到自己声明完成。

3. **串行真串 / 并行真并**：两模式各按 §六块 3 硬判据 3/4 通过。
4. **父卡让位**：子卡未终止期间父卡不起新轮。
5. **停得住**：停止 ⇒ 不再起新轮 ＋ 子卡停 ＋ 锁释放。
6. **可复原**：全过程可从 `logs/` 与 timeline 复原（每步调了什么工具、有无越权、有无犯错）。
7. **权限真的全开**：auto 卡工具面＝全量；`refresh_perms` 不冲。

   内容写入节与全权一致、含 §自动模式）；非 auto 卡拿到的是 `BASE_PROMPT`（**逐字节 == 现版**）。
9. **零回退**：非 auto 卡工具面 / 权限 / 停止行为 / **上下文**逐字不变；pytest 失败集与基线逐条同。
