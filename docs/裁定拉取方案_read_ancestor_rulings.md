# 裁定拉取方案 · read_ancestor_rulings（提议·待裁）

来源：card_046「裁定记录 · 卡片对话上下文注入」→ 对应 card_015 §五-1（目前未裁定）

## 目标
让卡片对话在需要时拉取血统链上级卡的「## 定论」区段，作为上下文参考，而不是常驻注入。

## 方案要点
1. 新增只读工具 `read_ancestor_rulings`。
2. 只返回血统链上级卡的「## 定论」区段，不返回「## 使命」「## 现状」。
3. 结果只作为工具返回值进入当前对话上下文，不常驻、不推送、不写回被读卡。
4. 权限与 can_read 一致：只能读取调用方有权访问的上级卡。
5. 定论为空时返回「无定论」。
6. 每次拉取的目标卡和字节数记入 prompt 日志。

## 验收项
- 验收1：只返回上级卡「## 定论」区段，使命与现状不出现在结果中。
- 验收2：结果不写入任何卡片正文或影子卡。
- 验收3：无权限的上级卡不返回内容，行为与 can_read 一致。
- 验收4：定论为空时返回「无定论」；每次调用在 prompt 日志中留下目标卡 id 与字节数。
