## 四、关键裁断（已替你定的细节）

| # | 裁断 | 理由 |
|---|---|---|
| 1 | project 放独立 `root` scope，不进任何树的 L1 | 树词表只约束子卡 ⇒ 子卡写 project 被闸2 自然拦截，零新增闸逻辑 |
| 2 | 创建期根卡识别用判据③（project_class+无 work_card_id），不加 is_root 参数 | 机械、零调用方改动、零类型语义；create_work 本就传 project_class |
| 3 | 根卡保护放宽为「剧本→project」单向迁移对 | 迁移完成后分支自然死路（盘上再无剧本根卡），无需回收 |
| 4 | 闸3 owner 改正向判据 `!= sub_project` | 负向判据（legacy∪剧本）在 legacy 全退役后恒 False＝闸3 失效；正向判据才是原意「owner 必须是子项目卡」 |
| 5 | 映射逻辑放 create_card 单处，三个入口自动适配 | 与「唯一写门」同哲学：一个口子，不散装 |
| 6 | 根卡迁移走 update_card 放宽分支，不直改文件 | 只走唯一写门（研究树批次同款），快照留痕 |
