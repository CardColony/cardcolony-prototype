## 4 画布与卡片节点

### 4.1 布局铁律
- **同一深度永远同一列**：`x = 48 + 深度×366`（NW=290 + GAPX=76）。纵向按子树次序紧凑堆叠、父卡居中于其子卡。层级是这一屏唯一必须显式表达的东西，宁可留白，不为填满挪 x。
- 折叠＝重排：收起一支，其余卡重新紧凑堆叠（不留洞）→ 总尺寸变小 → 画布自动放大 → LOD 升档。展开反之。**折叠与缩放是同一个密度旋钮的两端。**
- 画布永远画全树（折叠的支除外），没有「换层/下潜」。

### 4.2 节点解剖（290×84 起，四段固定）
1. **类型行**：▾ 折叠钮（有子卡才有）· 类型徽标 · 状态词（带色点）· **模型徽标** · 子卡数徽标。
2. **标题行**：标题（+归档码，若有）· 悬停动作 ◧ 对话 / ▣ 归档（根卡无）/ ✎ 改名（悬停显形）。
3. **事实行**：键值对（轮次·阶段·子卡·引用…）。
4. **最近更新行**：`时间 + 一句话`（仅 ultra 档显示，替换事实行，同高不撑破）。

### 4.3 卡类型体系（2026-11 定）
| kind | 名称 | 视觉 | 画布 |
|---|---|---|---|
| master | **Master Agent Card**（原根卡） | 左条 4px，徽标实底反白，标题 15.5px | 上 |
| manager | **Manager Agent Card**（原一级子项目卡） | 左条 3px | 上 |
| unit | **Unit Agent Card**（原二级及以下，**新拆分**，权限小于 Manager） | 左条 2px | 上 |
| worker / qa / pm / ui | 保持原名 | 无左条、**虚线框**、浮起浅底、工种图标 ▦ ✓ ✎ ◱ 各一色 | 上 |
| function / role / review / shadow | — | — | **不上**（定义即不进画布/卡树/统计） |
| rule（规则卡） | — | — | 不作节点上画布，但**右缘必须有入口**（§7.2） |
| topic（课题卡） | 本轮从需求取消 | — | — |

`type` 一律由 `kind` 派生（`KINDS[kind].n`），数据里不许另写一份。类型色三处同源：卡面左条 / 类型徽标 / 底部模型条同名格。

### 4.4 状态词（后端真实取值，非自造）
三层互不替代（依据 `config/card_type_registry.json → state_machine`、`static/canvas.js:1843-1862/6648`）：
- ① 生命周期 `state`：active ↔ completed（可回退）。画布上不单独出词。
- ② 自动推进 `goal_state`（仅 auto_mode=true）：active→**运行中** / paused→**已暂停** / complete→**已完成** / blocked→**受阻**。
- ③ 实时推送 `live`（/api/nav/running 流）：`running`→**运行中**（带「第 N 轮 · 当前步骤」）与 `queued`→**排队中**（10 分钟没轮上就撤标记）。
- **受阻 = auto_mode && goal_state==='blocked'**：自动推进卡住、需要人处理。不等于「有外部依赖」。「待裁定」不是任何字段——它降为卡面内容里的一条待办。
- 关键区别：运行中是**动的**（呼吸），已完成/受阻/已暂停是**静的**。一眼扫过去，还在动的就是要等的，不动的可以去处理结果。
- far 档受阻/暂停/排队用左侧 3px 色条顶出来（字看不清时状态仍可扫）。

### 4.5 LOD 信息分级（随缩放自动）
| 档 | 触发 | 显示 |
|---|---|---|
| far | <58% | 标题+状态+子卡数；类型徽标缩成带色图标（文字 0 号）；模型徽标压短**不摘**；受阻/暂停/排队左侧色条 |
| near | 58–71% | +类型行文字、前 2 项事实 |
| full | 72–95% | +事实全量 |
| ultra | ≥96% | 事实行**替换**为「最近一条说了什么」（同高替换，不撑高卡片） |

LOD 档位在过渡末（390ms）才切，避免缩放途中文字跳变。

### 4.6 已归档
归档不是卡片状态：`card_store.py:1882-1890` 归档会**删掉 cards 那一行**、整行 meta 进 card_archive 表。所以画布上**没有**已归档节点的格子。归档记录与回档走右缘「▣ 归档」浮窗（§7.4）；顶栏只有不可点的计数。

## 5 手势（画布）

| 手势 | 行为 |
|---|---|
| 滚轮上下/左右 | 平移画布（画布自己就是「页面」，无原生滚动条） |
| Shift+滚轮 | 横向平移 |
| Ctrl/⌘+滚轮 | 以光标为锚缩放（25%–200%） |
| 左键拖空白 | 平移（不设框选） |
| 触屏双指拖 | 平移画布；**单指不接管**（留给点卡片/按钮） |
| deltaMode 归一 | Firefox/按行滚的鼠标换算后同样可用 |

**手势永不过渡**：拖、滚轮、触屏全部 `animate=false`——过渡会让画面追不上手。只有折叠/展开/适配/定位/推流走动效。

## 6 卡面交互

| 动作 | 行为 | 备注 |
|---|---|---|
| **单击卡片** | 折叠/展开该支（联动缩放重排）；无子卡的卡单击不响应 | 与双击共处一卡，**延迟 200ms** 等双击判定窗；卡上 ▾ 是零延迟直通入口 |
| **双击卡片** | 打开这张卡的对话浮窗 | 双击第二下（e.detail>1）撤销待执行的折叠——画面不抖 |
| 双击同一张（对话已开） | 收起对话浮窗 | |
| 双击另一张 | 换成那张的对话（浮窗只有一个，旧的自动让位） | |
| 点浮窗以外任何地方 | 收起对话浮窗 | 卡片本身不算「外部」：卡上单击/双击语义不被浮窗改写 |
| ◧（卡上） | 零延迟打开对话 | |
| ▣（卡上，根卡无） | **归档**：该卡连同子卡整支退场（280ms 淡出）、其余卡重排、记入归档记录与事件日志 | 归档＝保留过程、可回档，所以**不弹确认**——可逆的动作不该先问一遍 |
| ✎（卡上，悬停显形） | 就地改名：contentEditable，Enter 提交 / Esc 取消 / 失焦提交 | **只改标题节点文本，其余 DOM 不重建**——当次点击不会被吞 |
| 模型徽标（卡上） | 点开模型选择浮层，**只改这一张**（覆盖值，不动类默认） | 显示端点报的模型名原文，前端不改写、不配简称；字长 CSS 截断+悬停全文 |
| 悬停卡片 260ms | 摘要浮层（§9.1） | |
| 拖动卡片 | **改归属**：按住移动 >6px 进入拖拽；只有被拖的卡跟手（子孙留原位变淡）；落到另一张卡上→目标亮起+提示「松开·「A」归「B」管」，松手生效：换父、重排、连线重画、记事件；落到自己子孙上→标红拒绝（会成环）；落到空白→放弃走回原处 | 根卡不参与拖拽；拖起后 80ms 内的 click/dblclick 全忽略 |
| 点外部（浮窗开着时） | 收起浮窗（捕获阶段监听，按钮的 stopPropagation 拦不住） | |

## 7 右缘书签组（三个入口，一支书签）

`.re-group`：贴右缘竖排一支，段段相接（上下端外圆 7px、中缝直角、段间一条贯通分隔线）。容器统一定位与避让——右缘任一浮窗开着时，**整组**平移到浮窗左缘（right 10→414px）；再点入口或点外部收回。**一套交互，不做两套**：点击展开 / 再点收起 / 点外部收回 / 浮窗互斥（同时只开一个）。

### 7.1 ☰ 事件（全事件日志，最上段）
- 副标题：`共 N 条 · 项目级事件自动记录（不含对话）`。
- 记的口径：**项目级**事件——建卡、归档、回档、归属变更、模型变更、规则编辑。对话内容不进来（那是某张卡自己的事，去卡上 ◧ 看）。
- 新事件自动插最上面；浮窗没开时入口计数 +1 并高亮（只是「有新动静」提示，不弹任何东西）；打开后清零。
- 本页发生的动作就地入账（演示口径：本页发生什么记什么，不造假条目；生长演示重放不入账）。

### 7.2 ▤ 规则卡（中段）
- 点开是**规则卡本体**（一张卡，不是面板）：类型/适用范围/版本/策展人 + 按 `##` 分区列内容（all / sub_project / ui / worker / function.qa）。
- 每区「编辑」→ 就地文本域 → 保存/取消；改过的区标「已改」。编辑中按 Esc 只取消这一次编辑，不关整张卡。
- 页脚明示：改动只在本页生效（演示），真实改动要经用户同意才落盘。
- 规则卡作为**节点**不上画布（挂到哪支下面都等于说「只有这一支受它管」），但**必须在画布上有入口**——右缘这段就是。

### 7.3 ▣ 归档（下段）＝已归档记录 + 回档
- 列已归档记录：标题+编号 · 类型 · 归档时间 · 原因码 · 为什么（并入哪/带几张子卡）·「回档」按钮。
- 回档＝恢复成活卡：作为新节点长回画布（带生长动效）、在视野内、记事件。
- 没有记录时空态写明：归档入口在**卡面**（悬停卡片，标题行右侧 ▣）。
- 归档记录清空后入口仍常驻（显示 0）——痕迹入口不消失。

### 7.4 浮窗规格
对话 392px / 归档 404px / 规则卡 404px / 事件 432px；贴右缘、上下留 10px、不全高、圆角 8px；头部标题+副标题+✕，底部提示+「回画布」。

## 8 底部全局模型配置条（44px 常驻）

- 按类型七格：Master / Manager / Unit / worker / QA / PM / UI。每格两行：上行＝类型图标+类型名+卡数，下行＝该类当前模型（端点原名）。
- 点一格 → 模型选择浮层（与卡面共用同一个浮层）→ 选定后**该类全部卡**的卡面徽标同步刷新，记事件。
- 卡面改＝覆盖值（只这张）；底栏改＝类默认（该类全部）。两者不冲突：卡面是覆盖，底栏是默认。
- 它是**配置不是操作**：常驻、不随画布缩放平移、不叠在卡片上。某类卡数为 0 时该格置灰（显示 —）。
- 全名比简称长一倍，横向一排塞不下——竖着分行是唯一既显全名又不截断的排法。

## 9 覆盖层

### 9.1 悬停摘要 tooltip（260ms 延迟，150ms 收）
- 说完了：宽度随内容自适应（250–460px），**全文换行、一个字不截**；头部=标题+编号+状态；正文=最近一条（谁+全文+时间）；底部提示行「最近 3 条 · 单击折叠/展开 · 双击对话 · ✎ 改名 · ▣ 归档」+ 就地输入框（Enter/发送就地回复，更新卡面最近一条）。
- 还在流式输出：**只占一行**、行尾闪烁光标、头部补「输出中」标——内容每秒变长，铺开全文会让浮层一秒跳三次高度。
- 拖拽中不弹；输入框聚焦时不收。

### 9.2 命令面板 ⌘K（Ctrl/⌘K 或 ⌕）
- **只搜卡**（标题/编号过滤），点结果=定位（同左栏：不选中、不淡化、不进模式、面包屑不变——点完你还是原来那个你，只是看见了那张卡）。Enter=第一条。
- 没有命令分组：命令都在顶栏按钮上，不重复一份。✕ / 点外部 / Esc 关。

### 9.3 更多菜单 ⋯
点开下拉；条目见 §2。点外部/Esc 收。

### 9.4 演示坞（左上 28px 胶囊）
默认收起；点开是演示项：四态（正常/加载/空/错误/无权限）+ toast。不占主视野。

### 9.5 四态演示（画布左下 372×250 小面板，不遮屏）
| 态 | 呈现 | 出口 |
|---|---|---|
| 加载 | 骨架屏 + 「正在取卡片树」——**≠空** | 演示坞「正常」/ 关闭示例 |
| 空 | 「数据已取回·一张卡都没有」+「不是没取到——是确知为 0。卡由模型建（create_card / create_worker_card），人只看与归档」 | 关闭示例 |
| 错误 | 502 码 + 就地「重试」（重试走 loading→normal）+ 保留上次结果 | 重试 / 关闭示例 |
| 无权限 | E403 · 缺 cards:read + 「向根卡申请只读」 | 申请 / 关闭示例 |

### 9.6 改动对照面板（右下）
默认折叠成一条头；点开列 59 条「原型 → 本图 → 为什么」。它是给用户逐条判断留改的凭据。

### 9.7 toast：**不做**
操作不弹提示条——折叠的结果是画布真的变了，定位的结果是那张卡真的在眼前，结果本身就在界面上。`toast()` 保留为 no-op 签名（防散落调用点报错）。**遗留调用点见 §14**。

## 10 动效（只服务理解，不做装饰）

### 10.1 折叠/展开/适配/定位
- 画布 `transform` 400ms 过渡，画面连续放大缩小，不闪切；节点位移 380ms；连线逐帧跟随（读过渡中的实时 left/top 重画 path，结束回落）。
- 退场不是「啪」一下：被收起的卡缩回+淡出 280ms 才移出 DOM；同 280ms 内展开回来会撤掉退场，不出残影。
- LOD 档位推迟到过渡末（390ms）切。
- 过渡期间百分比读数按**实际矩阵**逐帧写（矩阵还在 77% 时标签不会先写 85%），结束落目标值。

### 10.2 手势永不过渡
拖画布、滚轮、触屏双指全部无过渡——过渡会让画面「追不上手」。

### 10.3 自增长（后端推流的表达）
- 新卡先出现在**父卡右下方**（NW×0.55, ROWH×0.5），强制一帧落定（void offsetWidth），再 380ms 走到自己的列位；其余卡同时被推开；连线逐帧跟随；画布重新适配也是过渡。一步只加一张——推流是一张一张到的，不是整片刷新。
- **新卡不许出画**：每长一张核一次——装得下就只平移把新卡拉回视野（画面不缩放）；真装不下才重新适配。
- 父卡折叠着会先展开（新卡到了要看得见）；父卡子卡数徽标只重画那一张卡，其它 DOM 不动。
- **▶ 从根生长**演示：快照当前树 → 收回非根卡（退场 280ms 后才适配，否则退场中的卡会被瞬间甩出视野）→ 画布放大到「一张卡」的比例 → 按深度从浅到深逐张长回（父卡必先于子卡出现），一层长完停一拍、适配一次 → 收尾再适配一次消残差。用当前树本身（快照→收回→长回来），点几次结果一样，可重放；演示不入事件日志。
- **刷新不闪卡**：位移过渡加闸（`#nodes.anim` 只在明确要走动效的动作时开 480ms）；新节点先落 left/top 再进 DOM，首帧就在自己的位置上。没有前一个状态的位移都该是静止的。

### 10.4 通信线＝流星（信息传递那一下的表达）
- 依据旧系统原话（canvas.js:3940）：「画布上出现的每一条通信线都意味着『刚刚发生了信息流动』」。
- 一条传递三段：**信号头沿曲线飞过去**（头亮 r3.4+光晕，0.62s）→ **到站停一拍**（收件端点亮+扩散一圈，1.35s）→ **整条渐隐消失**（0.85s）。线上不留任何东西。
- 拖尾按**弧长**取（70–240px），不按参数比例——短线不糊、长线不断；每段独立 path，stroke-opacity 0.04→0.76、stroke-width 0.9→3.5 递减（CSS 不支持沿路径渐变）。
- 全部按性能时钟逐帧算（SVG 每次重画会重置 CSS 动画，不能用 CSS 动画）。
- 曲线（穿过中间的卡不会被误读成父子线）；收件端实心点=「信落在这里」。
- 演示窗口 12 秒（旧系统 30 分钟）；发一条消息=从父卡到该卡拉一条流星。一条线都没有=如实的「此刻没有人在传信」。
- 「更多 ⋯ › 关系线」可整体开关通信线显示。
- 有线在画时逐帧重画（rAF），一条都没有时自己停，不空转。

### 10.5 无障碍
`prefers-reduced-motion: reduce` 下全部过渡/生长动画关掉。动效不改变任何状态与判据。
