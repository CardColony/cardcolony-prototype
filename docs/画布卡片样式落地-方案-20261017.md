## 3. 落地设计

### 3.1 卡面重构（createNode 重写）

**新 DOM（根卡与子卡同模板，差异由数据驱动）：**

```
.card-node[data-id][data-type][data-lifecycle]
  ├ .msg-badge                      （保留：未读角标，喂 D18 气泡信号）
  ├ .cbody                          （卡体列）
  │   ├ .rcore                      （内容区——icon 锚定基准，D27）
  │   │   ├ .tname   项目名/卡名     （根卡 21px；无类型标签，D1）
  │   │   ├ .summary 三行状况        （status_block 前三行，各行省略，D2）
  │   │   └ .subctl  icon＋数字      （绝对定位 right≈6-8px、top:50% 于 rcore，D19/D20/D27）
  │   └ .bubble                      （新消息气泡，有才存在，D18；根卡态 margin-top:auto 贴卡底）
  └ （ttype/meta2 删——类型文字与更新时间从卡面退役）
```

- **ttype 删**：类型由左条色＋色表表达（D1/D17）。
- **summary 三行**：`getSummary` 快路径与回退路径同步改三行（`conclusion_summary` 契约不动，前端切三行）。
- **subctl**：单 `<svg>` 内两组（`ic-closed` 叠卡 / `ic-open` 扇形），`.on` 类翻面；展开态 icon 30→40px、数字 16→21px 加粗、`color:var(--cc)`；点击＝toggleExpand（复用 bindNodeEvents 路径与 updateExpandBadge）。**锚=.rcore 中线**：rcore 只包内容不吃余量（无 flex:1），气泡的 auto 上边距吃余量贴卡底——气泡在 rcore 之外，结构上不参与中线计算（D27）。icon 几何：两态可见中心均＝viewBox 中心（收起叠卡 y7–33、展开绕支点 (20,29)±20°），切换不跳轴。
- **根卡 360 / 子卡 330**（D25）；根卡 `min-height≈292`。
- **退役灰阶**：`data-lifecycle="retired"` 驱动实体暗灰卡（3.4）。
- **LOD 适配**：.l0 只显 tname＋subctl；.l1 名字＋状况＋subctl；.l2 全量（含气泡）。subctl 全档保留（树的入口不许丢）。气泡仅 .l2 显示（卡海保护）。

**CSS**：style.css 卡片段按上结构重写；黑白灰令牌作用域见 3.5。

### 3.2 新消息气泡（取代 1016 版"消息卡"整节）

**结构（卡内、rcore 之后）：**

```
.bubble[data-card]
  ├ i.bnew        NEW（红壳 #e5484d·白字·右上角，D21）
  └ span.btxt     消息正文（两行窗）
```

- **显隐规则**：无新消息＝DOM 不存在（非 hidden）；对话新消息信号到达＝自动长出并流式；点开弹窗＝NEW 摘除（气泡留正文）；再来新消息＝NEW 回归。退役卡永远无气泡（不发不收）。
- **两行窗**：`max-height≈42px / line-height 1.6 / overflow:hidden`——**无滚动条、无省略号**；超出部分被窗裁掉（动态提醒非阅读窗，全量阅读走弹窗）。
- **流式**：对话增量逐字追加进 btxt，同时 `scrollTop=scrollHeight` 跟随。信号源见 §10-T1（card_message 帧是卡间消息信号——气泡要的是**对话流**帧，补勘后定：复用或新增 `message_delta`）。
- **泡形**：圆角 12px（左下角 4px）；尾巴＝`::before` 45° 尖角，`bottom:-5.5px; left:14px`——底边左下角向下伸（D22）。浅灰底 `#272727`/边 `#3c3c3c`（黑白灰系）。
- **对称留白**：左右 margin 差补边框差（卡左条 3px/右边框 1px → `margin-left:-10px; margin-right:-8px`），实测左右留白严格相等。
- **点击气泡＝开弹窗**（3.3）。**卡上无输入框**——发消息一律走弹窗（D18）。
- **布局**：气泡在卡内，`measureSizes` 实测卡高即含气泡——**1016 版"布局补偿 MSGCARD_H"整节删除**，连线/避让零额外处理。

### 3.3 弹窗系统（popup-manager，canvas.js 内独立节）

- **形态**：640×640 正方、屏幕居中、消息流独立滚动（D7）；头部＝卡名＋⇥＋×(40×40)（D9）；**无色无流光**（D16）——中性灰边框，仅 D12 两段动效。
- **多窗秩序**（D8）：打开顺序错位 40px；重复点聚焦不新开；Esc/遮罩关最上层；同列吸附窗不受 Esc 影响。
- **吸附**（D10/D11）：⇥ → 右侧**实测 `#rulePanel` 左缘**为基线（不猜常量），同列纵排、自上而下、单窗 320 封顶、不足整列均分压缩不溢屏、关中间自动上移；⇤ 弹回。吸附态无遮罩、画布全交互。
- **动效**（D12）：开窗 scale(0.82)→1 淡入 0.22s；⇥/⇤ transform 过渡 0.3s。只用 transform/opacity；`#probe` 模式禁动画不影响日常。

### 3.4 两状态（运转/退役）

**退役（持久态，lifecycle=retired）**：
- 卡面：**实体暗灰卡**——`#0e0e0e` 底 / `#262626` 边 / 左条 `#565656` 灰（D24，弃 grayscale 滤镜——滤镜在深底上近透明）。

### 3.5 色表与界面黑白灰

- **类型色表**（D17/D23）：`[data-type] → --cc` 六行 CSS 映射（剧本金/世界观蓝/行为体紫/节点橙/伏笔红/创意灰）；左条、流光、icon 展开态三处同源吃 `var(--cc)`；卡面本体不吃（D15）。新类型加一行选色。
- **界面黑白灰**（D23）：画布页作用域内——背景/面板/边框/文字/顶栏/缩放控件/弹窗/气泡/连线（#8a8a8a）/界面态色（输入焦点、悬停）全部中性灰（不偏蓝不偏暖）。生产 style.css 现为偏蓝深色系（#0d1117 系）——改造方式：**画布页作用域换中性灰令牌值**，类型色令牌 `--c-*` 原值不动；其他页面（workspace 等）消费的令牌**逐一排查**（§10-T2），被波及的需作用域隔离（§8 风险）。作用域边界最终依 §10-Q3 裁决。

### 3.6 画布导航交互

- **顶栏缩放控件组**（替换现只读 `zoomDisplay`）：`−` 按钮 ＋ 拖动条（180px：track/fill/knob）＋ 百分比 ＋ `＋` 按钮。
- **步进**（D28）：每按 ±25%（floor/ceil 到 25 倍数）；范围 25%–200%；到底/顶按钮 off 态（opacity 降、不可点）。
- **拖条**：pointer capture 连续设值，fill/knob/百分比实时跟。
- **滚轮**：`wheel` preventDefault → `panY -= deltaY`（上下滚动画布）——**缩放不再走滚轮**。
- **拖动平移**：空白处 pointerdown 起平移（双轴 transform translate）；起点 `preventDefault` 掐断"按住选文字"，拖动期整画布 `user-select:none`，松手恢复；起点落在 input/button/.subctl/.bubble 上不平移（控件可正常操作）。
- **缩放实现**：`world.style.transform = translate(panX,panY) scale(z)`，transform-origin 居中；现有 wheel 缩放代码（±10% 鼠标锚）整个退役。

### 3.7 连线生长动画（待验收 D30——验收过即转正）

- **改造对象**：`addElbowPath` 产出的直角折线（现挂线即现、常驻）。
- **生长**：path 挂上后量 `getTotalLength()`，`stroke-dasharray=len; stroke-dashoffset=len→0` 过渡（460ms ease）；到位后子端空心圆点浮现（opacity 过渡）。多条线按 90ms 错峰依次生长。
- **回缩**：收起时 dashoffset 反向回 0→len（300ms），结束后连同子卡一起移除。
- **接线点**：`toggleExpand` → `renderSubtree` 子卡就位后，对本次新增连线播生长；收起走回缩。纯 path 属性动画，不触发布局、与缩放/LOD 无关。
- **初始装载行为**（页面打开时已展开的树）：**依 §10-Q2 裁决**——A 初始收起（原型现状）/ B 初始展开＋开场逐条生长 / C 初始展开＋线直接就位（仅手动操作播动画）。

## 8. 风险与边界

- **并发施工**（最高）：三文件在飞——阶段 0 闸门不放行不开工。
- **黑白灰波及面**：生产令牌被 workspace 等其他区域消费——阶段 0 全量排查消费点（T2），作用域隔离（边界依 Q3），**不误伤范围外页面**。
- **浏览器实测**：弹窗动效/吸附排布/流光/连线生长手感必须真实人机过（探针测几何状态，测不了手感）。
- **lifecycle 拦截是行为变更**（退役卡发消息 409）——任务书单列、提交信息注明。
- **气泡×卡海**：L2 档多卡气泡首屏请求量——懒加载＋防抖（复用摘要懒加载模式）。
- 流光性能：仅 border 伪元素 conic 动画，多卡不触发布局；退役/探针态零动画。
- 连线生长性能：纯 dashoffset 属性动画，不触发布局；`prefers-reduced-motion` 尊重（探针态禁动画互不干扰）。
