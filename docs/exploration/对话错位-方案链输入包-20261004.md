## 三、已核实代码事实（今天现场实读，file:line 为本次读取值）

**对话主链路时序**（`src/api/routes.py` 主消息端点内）：

```
:343  prior = await session_store.read_session(work_id, card_id)      ← 先读历史（不含本条）
:346  await session_store.append_message(..., "user", content)         ← 再追加用户消息
:355  prior_for_gateway = [{"role":…, "content":…} for m in prior]     ← 只取两字段
   …   （三席并发 → 统合 → 工具循环，耗时分钟级）
:514  await session_store.append_message(..., "assistant", clean_text, model=model_used)  ← 最后追加回复
```

**关键结构事实**：读历史 → 写提问 → 跑模型 → 写回复，**全程无任何一步把「本次请求」与「本次回复」绑定**。

**会话写入实现**（`src/storage/session_store.py:53-67`）：

```python
header = [MARKER, f"role: {role}", f"timestamp: {ts}"]
if model is not None:
    header.append(f"model: {model}")
...
async with aiofiles.open(path, mode="a", encoding="utf-8") as f:
    await f.write(block)
```

消息字段：`role` / `timestamp` / `model`（可选）/ 正文。**无请求标识字段。**

**统合输入组装**（`src/api/simple_service.py:28, 46-57`）：

```python
VIEWPOINT_HEADER = "## 其他模型的输出"

def build_viewpoint_prompt(user_prompt, ok_metas):
    if not ok_metas:
        return user_prompt
    sections = "\n\n".join(f"### 输出 {i + 1}\n{m['text']}" for i, m in enumerate(ok_metas))
    return f"{user_prompt}\n\n{VIEWPOINT_HEADER}\n{sections}"
```

**前端发送路径**（`static/workspace.js:446-485`）：`send()` 内先 `appendMessage("user", content)` 立即上屏，再 `await API.sendMessage(...)`；`tryRecover()` 每 15 秒查一次会话记录，若后端已完成则从记录恢复。

**日志落盘**（`src/api/prompt_log.py:36`）：`path = LOGS_DIR / f"prompt_{card_id}_{stamp}.json"`
