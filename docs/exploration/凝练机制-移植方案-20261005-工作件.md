## 一、功能背景（为什么做）

**问题**：对话历史无界增长。实测硬数字——单次调用 prompt 最大 534,657 B，会话文件 `session_001` 已 171 KB。T11 装配线治「这一轮怎么摆」（结构）＋工具轮折叠（轮内压缩替身）；**治不了「历史越积越长」**。凝练线对准：把已发生的历史折成常驻记忆，原文一条不删、水位前不进上下文但可按锚点取回。

## 三、数据设计

### 3.1 记忆链单位＝卡片对话（一卡一会话一记忆链）

- 键＝`(work_id, card_id)`；落点 `works/{work_id}/memory/{card_id}.json`——**不写卡片 front matter**（守 10-02 拉取制红线：卡片正文仍只能经 read_card 拉取；记忆条目 ≠ 卡片正文，前者可常驻、后者仍走拉取）。
- **一卡一会话是推演现状**（`session_store._session_path` L38-40），凝练不改变这个结构，只在它之上加记忆层。

### 3.2 位置标识（替代 dsh 的 seq）

- 用 **`{card_id, 文件内块序号}`**——`session_store.read_session`（L120）逐块解析循环天然可现算块序号，**无需改存储格式、无需新增字段、读时现算**（p1 实读证实；header 无 seq 字段 L90）。
- 水位 `condenseMark`＝「已凝练到的块序号」，**存 `memory/{card_id}.json` 内**（半开区间：mark 前已凝、对上下文不可见；mark 后未凝练）。

### 3.3 记忆条目格式（对齐 dsh L1 四栏，但属推演侧自己的格式）

```json
{
  "card_id": "...",
  "mark": <块序号>,
  "entries": [{
    "seq": <锚点位置——会话文件第 N 块>,
    "conclusion": "【结论】一句话",
    "evidence": "【依据】工具名+参数+原文位置",
    "occurred_at": "...",
    "fingerprint": "sha256:..."
  }]
}
```

- 【结论】模型压出、**不设长度限制**；【依据】代码机械写（工具名+参数+原文位置）——照 T11 工具轮折叠同源范式（`tool_fold.py` L68-93 实证）。
- memory 文件独立于卡片与会话、**互不写入**。

### 3.4 席位

复用 main（`config/models.yaml` deepseek-v4.1-flash，统合官兼深度主模型）——不动 yaml 更小变更面。`models.yaml` 无实闸（max_tokens/timeout 全在注释块 L10-14，拆闸裁定原文；L30 context_window 是展示字段非运行时闸）。
