### M3 · 宽度：70% 自适应 ＋ 48em 门槛（用户 19:08/19:32 裁定）

```css
/* style.css:1060 替换 */
.msg {
  max-width: min(70%, 48em);   /* 原 min(82%, 720px) */
}
```

- **70%**：相对 `.chat` 内容盒，窗口越窄越收——用户 19:08 逐字裁定。
- **48em**：门槛值。`em` 跟随 `.msg` 字号（本次助手升 14px ⇒ 48em = 672px 内容宽；加 32px padding = **704px 外宽**）——**上限即 W3C「横排最大行长不宜长于 48 字」**。这是用户 19:32 明确要的「门槛值」；上版 71 行写「无固定像素上界」是错的（已被 19:32 裁定推翻）。
- **交叉点**：`.chat` 内容宽 ≈ 960px（672/0.7，四舍五入）→ 对应窗口 ≈ **1290px**。窗口 <1290px 走 70%（跟随窗口）；>1290px 封顶 48em（宽屏不再无限宽）。
- **U-3 立法意图恢复成立**：`min(70%, 48em)` 有上界（48em），不是裸百分比 ⇒ v2 里登记的「R3b 冲突」**解除**（详见 §六）。

**实测对照**（13px 现状版 vs 14px 文档流版）：

| 窗口 | `.chat` 内容宽 | 现状 720 固定 | 本次 `min(70%, 48em)`（14px） | 一行汉字 |
|---|---|---|---|---|
| 1280 | 905px | 720px | **634px**（70% 生效） | 45 |
| 1680 | 1305px | 720px | **704px**（48em 封顶） | 48 |
| 1920 | 1545px | 720px | **704px**（48em 封顶） | 48 |
| 2560 | 2185px | 720px | **704px**（48em 封顶） | 48 |
| 3840（用户显示器） | ~3536px | 720px | **704px**（48em 封顶） | 48 |

**如实说明**：宽屏下恒 704px（48 字）——比现状 720px 窄 16px。这是**门槛的语义**（用户 19:32 裁定要门槛）；若用户要更宽，门槛值可调（48em → 55em 即 770px，仍在「书籍 17-40 字」与「上限 48 字」的张力区间，取哪个值用户定）。
