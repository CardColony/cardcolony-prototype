## 一、设计意图摘要（十行，论证见规格件）

1. 原生模型：**每张卡＝一个对话＋一份档案，长在一棵树上；画布是这棵树的空间地图；根卡对话＝项目主对话。**
2. 五公理：无死角（含根卡）／树即导航／读优先／热度冒泡／反馈即时。
3. v1（T17）交付了三联外壳但拿「通用 agent 会话列表」当模板套树——学了皮丢了本体；v2 修可读性；v3 从旅程四区（续／谈／看／沉）整体定案；v4 转向原生模型。
4. 本方案落三件事：**导航会「走」**（根卡入口＋键盘＋冒泡排序）；**对话能「读」**（文档流＋Markdown＋IME 守卫）；**档案可「翻」**（Inspector 只读优先＋关系可点）。
5. 画布视觉（结构色三档上节点）后置待 canvas 解禁——不在本方案。
