## 三、操作手册（执行者照做，每步即验；作者只校对结果）

### 阶段 0 · 冻结 + 存档（本方案一切前提）

1. **停手冻结**：确认没有进程在写工作区（两条施工线、拆页编辑都停）。
2. **整目录复制到仓库外存档**：
   - 源：`D:\AI_station\推演agent`
   - 存：`D:\AI_station\推演agent_备份_20261016_烂摊子`
3. `git status --short` 全文另存进存档目录。
   **验证**：存档文件数与当前一致。

> ⚠️ 红线：任何一步失手，立刻从阶段 0 存档重来，不许在错误上硬缝。阶段 0 是唯一后悔药，先存再动。

### 阶段 1 · 找 workspace.js 的「拆页前最后版本」（最关键，先做）

不能简单 checkout HEAD（会丢 10-15 未提交的 ⋯、接线）。候选逐一核对：

| 候选 | 判定方法 |
|---|---|
| HEAD（1780 行） | 行数~1780=未手术；但可能缺最近未提交的 ⋯、接线 |
| `_e2e_static_tmp_dsh/workspace.js`、`_e2e_static_tmp_ss/workspace.js`（M） | 若是拆页前 e2e 快照，可能是完美靶子 |
| `git stash` 展开检查 | 看 stash@{0} 里有没有 workspace.js 拆页前版 |

**每个候选查三样**：① 行数（~1780=未手术）② 含不含 `from "./nav_system.js"`（含=手术版，不能用）③ 含不含 `data-newchild`/`.nav-plus`/`wid + ":"`（含=最新左栏，好）。

**选靶**：优先选「未手术 且 含最新左栏」的；没有就用 HEAD，接受丢最近未提交的 ⋯、接线——那一小段按 `docs/左侧边栏-*` 记录事后补回（有据可查，不是猜）。

### 阶段 2 · 每个 M/?? 文件判归属（B 撤 / C 保 / A 保 / 待判）

按特征判：
- 含 `nav_system`/`page_bus`/`main_chat` 引用 = 拆页（B）→ 撤
- 在 `src/model_gateway/`、`llm`、`model_service`、`model_config`、`event_stream`、`errors`、`test_llm_*` = llm 线（C）→ 保，碰都不许碰
- `nav_render.js` 等左栏文件 = 左栏（A）→ 保留工作区版
- `rule_panel.js`、`stream.js`、`home.html`、`settings.html`、`api.js`、`home.js` = **待判**，逐个 grep 谁引用决定——尤其 `rule_panel.js`，`040c0bb` 提交正与规则卡有关，可能是规则卡线的，删前必须查清，被引用则不能删。

**红线**：每个待删文件名，删前先 `grep` 全仓引用者；被 C 或现有主功能引用的，单独上桌判断，不许顺手删。

### 阶段 3 · 撤回操作（逐个来，每撤一个验一个）

**删除**（HEAD 里没有、确认拆页新建、无合法引用）：
`templates/card.html`、`static/esm/main_chat.js`、`static/esm/nav_system.js`、`static/esm/page_bus.js`（若 rule_panel 判为拆页则一并删，未判清不动）。

**还原**（`git checkout HEAD -- <文件>` 或 cp 阶段 1 靶子）：
- `templates/work.html` → HEAD
- `main.py` → HEAD（若确认路由改动仅拆页；否则手工只删 card 路由那两段）
- `static/esm/main.js` → HEAD
- `static/canvas.js` → HEAD
- `static/workspace.js` → **阶段 1 靶子版**
- `static/esm/api.js`、`home.js` → 按阶段 2 判定：仅版本戳/路由则还原，含左栏成果则仅去除拆页引用

**每步验证**：该文件不再含 `nav_system`/`page_bus`/`main_chat` 引用；`git diff` 该文件为干净或已还原。

### 阶段 4 · 验证恢复可用

1. `git status`：拆页新增文件消失、B 文件回 HEAD/靶子、**C 文件与存档逐字一致（md5 比对）**
2. `node --check` 关键 js（workspace.js/main.js/canvas.js）
3. 重启服务，打开 `/work/{wid}`：画布+对话单页可用
4. 左栏功能逐项点：展开、搜索、点卡进对话、运行中
5. 跑前端 nav 测试确认左栏没被还原弄坏
