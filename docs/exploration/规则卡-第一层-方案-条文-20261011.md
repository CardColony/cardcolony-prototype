# 规则卡 · 第一层「方案」

## 这一层管什么

方案是你动手之前的判断落点。它唯一的作用是：**让你的判断在付出代价之前，有机会被人推翻。**

所以写方案不是记录"我打算怎么做"，是摊开"我凭什么这么打算"。判断没摊开，等于没被检查过。

## 条文

**一、每个判断写清三样：我基于什么、我判断什么、为什么不是别的路。**

只给结论，别人挑不出错——你的错误在前面那个前提上，后面的推理是自洽的。要让人看出来，只有把前提摆到明面。

**二、每条设计指回它的出处。没有出处的新增，自己标明"这是我加的"。**

下游拿方案当地基，不会替你判断：漏掉一条，它静默消失；多出一条，它照做。

**三、能定的定死。定不了的，留一个明码的岔路：这里有个什么选择、该谁定、不定会怎样。**

你选了一条却不标出来，岔路就消失了——在人眼里看起来根本没有岔路。事后才发现，代价是返工或者忍着。

**四、分清哪些该你定：改变"别人看得见的结果"的，是别人的；只改变"你怎么做到"的，是你自己的。**

把自己的选择端上去问，是烧别人的时间；把别人的选择自己定了，是越权。分辨只在这一点上。

**五、写清"什么算违反了这份方案"。**

动手时一定会撞上写它时想不到的情况。没有这一条，方案会被实现过程追上、越过，然后失效——变成一份没人再看的旧文件。

**六、标出你还没想透的地方，和"待别人定"分开写。**

你最危险的状态不是不知道，是不知道自己不知道——你会用和确定一模一样的语气，说出其实没把握的判断。

**七、写完就停，不动手。**

边写边做，判断没被拦过就已经进了产物——方案退化成事后记录，它前瞻的作用一点不剩。

## 这一层管不到的地方

**这七条治的是"判断没有被摊开"，治不了"判断能力不够"。**

如果它确实想不出更好的路，条文只能让它把这条穷途如实写出来（第六条），不能凭空给它一个更好的判断。**规矩能保证判断可见，不能保证判断高明。**

这个缺口是明摆着的：摊开的前提错了，只要人没看，错照样往下走。所以这一层真正的下限，取决于有人看。
