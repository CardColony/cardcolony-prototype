## 一、样式轮增量（v1 → v2）

10. **工具卡不进左侧边栏。** 建树时先把工具卡（连同其子树）整棵剥掉。
    原型数据里故意留了一个工具卡样本（基建三 → 「剧本 · 方案链」）供自检验证"真的被剥掉"。
11. **灰只有一处含义：行尾时间＝次要信息。** 上一版把灰用在三处（冷卡标题/冷项目图标/时间），
    等于没有定义；且"冷不冷"排序已经说了，标题再涂灰是重复表达。冷灰全删，标题与图标永不涂灰。

## 二、交互轮决定（每条带为什么）

12. **只有四个动作：找、开、看、收放。** 其余一切衍生。五条不变规矩由此推出：
    ① 一个点击目标一个含义、不随数据变；② 你点的那一行原地不动；
    ③ 你亲手摆好的展开收起系统不许改（只有"打开/定位"可撑开路径）；④ 搜索是镜片，不改动任何东西；
    ⑤ 状态自己变，但绝不动你的视野（绝不自动滚到运行中的卡）。
13. **箭头判定区 24px**（比图案大，好点），悬停时箭头下浮出圆角灰底，让你看清这块=展开/收起。
14. **最近活动过的卡（含二三级）默认露出**：48h 内动过的卡连同到根的路径默认可见；
    一级子卡按最近活跃排序、活跃分支默认展开、冷掉的默认收起。
15. **点标题＝进这张卡的对话**（行上除箭头、除 ⋯ 的任何地方）。打开时自动撑开路径 + 滚到 + 高亮。
16. **悬停行尾浮出 ⋯ → 菜单两项：新建子卡 / 删除。**
17. **⋯ 必须落在"时间原来的位置"上**（用户 18:43 指正）：不是"隐藏时间、⋯ 待在老地方"。
    实现＝行尾一个 `tail` 槽；时间让位用 `opacity:0` 保留占位（槽宽不变），⋯ 绝对铺满该槽居中。
    自检新增位置断言：⋯ 中心与时间原中心偏差 ≤3px。
    只有转圈（运行中）时 ⋯ 排在转圈右边——转圈不让位（它是活的状态）。
18. **展开/收起不跳**：点谁谁钉在屏幕原位，变化只发生在它下面；无动画（一天点几十次，动画=不跟手）。
19. **搜索是镜片**：全树命中（折叠里的也能显出）、命中字标黄、清空后展开状态原样回来、
    Enter 打开首条命中、Esc/× 清空；项目名也搜。

## 三、自检覆盖（?check=1 全过）

线不变量全过；根卡行无线；一级子卡行无拐弯线；父卡子列从父 icon 下缘连到末子 icon 中心不断线；
线不压任何外列图标；最近活跃默认露出；同级按最近排；箭头判定区 24px；
展开/收起点哪行哪行不动；搜索镜片显出折叠命中且不改状态；打开＝撑开路径+滚到+高亮；
⋯ 菜单新建/删除真实生效；⋯ 落在时间原位（≤3px）；运行中与时间互斥、转圈不让位；
Enter 打开首条命中；无工具卡；标题无冷灰。
