## 三、三个既有机制的现状核对（任务书红线前提）

1. **`prompts.py:70-74`**：`build_system_prompt` 有**两条分支**——`if context_block and context_block.strip(): return BASE_PROMPT + "\n" + context_block.rstrip() + "\n"`，空 ctx 走 `return BASE_PROMPT`。**方案 V1 判据「空 ctx 分支与尾部空白（rstrip）两条路径都覆盖」的落点就在这**（对应 R-049）。
2. **`session_store.py:71-104`**：`append_message` 带 `pair_id` 可选参数、T10 落盘互斥锁（:57-68）——**任务书不得破坏 T10 已上线机制**（C-012 边界）。
