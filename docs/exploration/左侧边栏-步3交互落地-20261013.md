## 三、交互（定稿语义）

### 3.1 点名字＝打开这张卡（**永远**，与有没有子卡无关）
旧语义（有子卡＝展开、只有叶子才跳转）是「有子卡的卡永远点不进去」的根因，已退役。
- 实测：点「思维链」（childCount=1）→ hash 变、view=chat、**它自己没被展开** ✓

### 3.2 箭头＝只展开/收起（URL 不变）
- 实测：点箭头 → hash 不变、open true→false、行数不变 ✓
- 判定区 24px 宽整行高；图案自带一圈与行底色同色的描边，把穿过的竖线咬断。

### 3.3 搜索＝镜片（剪枝树，不是结果列表）
- 输入 → 树重投影成「命中 ＋ 它到根的路径」，命中那一段标黄；**路径行不着色**（它负责定位，不负责提示命中）
- **一个字都不写进 prefs**：query 只活在 temp 内存 ⇒ 清空即原样还原
- 镜片期间：不出箭头、不响应收放（没有可收放的东西）；点开命中卡顺手退出镜片
- Esc＝清空还原；Enter＝打开第一条命中
- 实测：24 行 → 2 行、标黄 1 处、`data-twist` 0 个；**清空后还原 24 行、标黄 0** ✓

### 3.4 ⋯ 菜单＝新建子卡 / 删除
- 删除的置灰判据不是新规矩，是把后端已有的结构性防护（不许删带子卡的卡）搬到眼前
- 实测：有子卡 → 删除 `disabled`、`cursor:not-allowed`；叶子 → 可点、`danger` 色 ✓

### 3.5 行尾同位（你 18:43 指正的那条）
⋯ 不是排在时间右边，而是**落在时间原来的中心**。
- 实测：`timeCx 277.1 = moreCx 277.1`，**中心差 0px**；悬停时时间 opacity→0、⋯ opacity→1 ✓

### 3.6 最近活跃分支默认露出（你 15:48 第 2、3 条）
- 判据：`branch_active_at` 距今 < 48h（后端已送该字段，零新增字段）
- 作用域：**只在已打开的项目内**。为什么不自动打开所有活跃项目——实测 13 个项目里 11 个的
  项目级活跃都在 48h 内（同一批被污染的时间戳），全开会把侧栏摊成一锅粥。
- 不覆盖 manual：你亲手展开的，系统永不收回。
