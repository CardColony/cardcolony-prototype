## 三、源机制铁证（15:02 实读所得，本次只需复验、不重复烧取证）

源侧（dsh 记忆凝练机制）**本就具备**：
1. **分批限量凝练**：攒够触发线才开跑一批；每批从「未凝部分」切一个窗口的量（每批预算），宁少不超；凝完本批、剩余留到下一批，批批循环到清空——**不是一次全凝**。
2. **每凝练满 N 批归拢一次**（折叠）：把同一事件散落的多条记忆合成一条完整、旧成员降层保留（信息不丢）。
3. **触发判定与窗口装载同口径铁律**（防"凝了一批还差很多才到线"的怪账）。

**推演侧现状（=漏搬处）**：
- 凝练：`pending = prior[mark:]` 一次全取、**无切片逻辑**；
- 折叠归拢：**整条未搬**；
- 触发按字节、切片另算——**必分叉**，同口径铁律亦未搬。
