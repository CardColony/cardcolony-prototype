## 4. 自主裁定清单（执行者自决，可推翻）

1. **阶段 0 先补 stale 断言**（`61ade59`）：裁定 C1/C2 无对象可落，但遗留 1 红必须清；
   该断言属「戳联动的尾巴」，补它符合裁定本意。
2. **导航系统边界**：`nav_system.js` ← 导航核心（:518–853）＋版本探测/运行总览＋通知面板；
   顶栏/窄条/新建项目三钮**留在 workspace.js**（任务书 A1.2 清单未列）。
3. **新增模块版本号挂 `v=30`**（nav_system / rule_panel 初始值）——「挂当前档」无更明确口径。
4. **`open()` 写 URL 由 hash 改路径**（`replaceState`）：A2.2「路径优先」若不同步路径，
   nav 点卡后刷新会回到旧卡（path 胜 hash）⇒ 必须同步。这是 A2.2 的隐含前提。
5. **canvas.js 加空守卫**（非画布页降级惰性）：任务书阶段顺序有缺口——阶段 3 的对话页
   仍会经 workspace.js 加载 canvas.js，而画布 DOM 已不在该页。若不守，阶段 3 无法验收。
   阶段 4 摘边后该守卫冗余（保留无害）。
6. **`scripts/run_test_instance_5701.py` 同步路由**：它自述「与 main.py 逐行一致」，
   不同步则烟测失真（本次即由烟测抓出）。属测试资产，非产品面。
7. **删当前卡后改整页跳转**（原 `setAppView("canvas")`）：纯对话页无画布可切。
8. **`handleProjectAdd` 无建卡钮时改跳画布页**：对话页无 `#newCardBtn`（原为静默无操作）。
9. **例外表 `OPTIONAL_IDS`**：仅收录**带 null 守卫**的跨页可选查找（`newCardBtn`/
   `childTitle`/`workspace`），并注明理由；阶段 4 已把阶段 3 的 canvas DOM 过渡例外删净。
