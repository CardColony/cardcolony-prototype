### 任务 2 · 对话区（C 系，workspace.js）
- **C2 渲染器 escape-first＋白名单**：以 `escapeHtml`（L18，现行唯一转义）为底，重建为「先转义全部、再按白名单还原受信标签」——白名单＝现行受信集（blocktitle/ws-edit/model-badge 等，任务书据现用集逐条列）。**杜绝 HTML 注入**（原先最先将用户文本拼入 innerHTML 的路径全部改走安全渲染）。
- **C5 IME 守卫**：keydown（L836-841）现仅 `e.key==="Enter" && (e.ctrlKey||e.metaKey)`，**无 isComposing**——中文输入法选字回车会误发。加守卫：`if (e.isComposing) return;`（全 static/ isComposing 现 0 命中=缺失实证）。
- **C6 send 增量记账与 DOM 一致**：send()（L676）绕过 renderChat 直接上屏（L568-569 注释逐字记「纯变量记账与 DOM 脱节」）——统一为 renderChat 以 DOM 实数为准（.msg:not(.thinking)），send 增量路径与之一致。
- **C8 用户气泡生态色**：`.msg.user`（style.css L925）现硬编码 `#1f3a5f`——改为取生态变量（与规格色彩体系一致、无硬编码）。
- 验收：注入测试（粘贴含 `<script>` 文本后不执行、输出为转义文本）；IME 断言（keydown 分支含 isComposing）；气泡无 #1f3a5f 硬编码残留。
