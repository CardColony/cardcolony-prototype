## 一、这段工作是什么

给推演系统加「凝练」能力，解决一个真问题：每张卡片一个独立对话，对话越聊越长，单次调用 prompt 实测最大到 534 KB，模型每次干活都得扛整个对话包袱。凝练＝定期把一段对话历史压成几条「记住了什么」的要点（【结论】＋【依据】），模型以后看要点就够了，不用回回扛全文。

整条线分两段走——**T12**（方案＋任务书＋阶段一/二＋阶段三基础件施工）与 **T15**（路线裁定后补的凝练管线本体施工），现已核验收口。
