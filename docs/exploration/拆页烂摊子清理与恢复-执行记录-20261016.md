## 3. 手术式还原（混合文件——不能整文件回滚）

`workspace.js` / `canvas.js` **同时**含「拆页」与「依赖关联线（`relations→links`）＋画板四机制 T1」改动。
整文件回 `042c0bb` 会把 `links` 一并退回，而 `GET /canvas` 已出 `links`（`canvas_store.py:172`）⇒ 画布关系线全丢。**故手术**。

**做法**：以 `042c0bb` 版为底，用带**计数断言**的一次性脚本重放非拆页 delta；任一条计数不符即整体失败、不写盘。

- `static/canvas.js`：只摘 5 处拆页引用（`import pageBus` → `import { Workspace, RenderNav } from "./workspace.js?v=35"`；`pageBus.openCard`×3 → `Workspace.open`；`pageBus.renderNav` → `RenderNav`）。
- `static/workspace.js`：重放 delta = 版本戳 4 处 ＋ `relations→links` 7 处 ＋ 画板 T1（`EventFlow.activate`／`ensureMsgs(cardId)` 函数体＋9 调用点／`EventFlow.stop(wid,cid)`×3）。

**自验**：`git diff 042c0bb -- <file>` 的差异**恰为**上述 delta，无多无少；`grep nav_system|page_bus|main_chat` = **0**。
