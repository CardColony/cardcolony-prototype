# 主界面实现线 · 梳理三节（proposal p15）

对账基线：源方案《主界面优化方案-20261007.md》（19,400B/213 行，每股改动项编号 B1-B12/C1-C9/D1-D5/I1-I7/E1-E3 与验收 N1-N12/E-1~E-7 均出自其上，与本线 p0 对账底册一一对应）。

## A. 功能背景（为什么做）

主界面重设计（T17）已在正式服上线（10-07 10:09，b7fd5bb）。用户首次实操后当场指出三处硬伤（10:12 三问）：

1. **色点含义无人懂**——导航里金/蓝/灰三色点（项目/有子卡/叶子）没有任何图例，且灰色与卡片类型色撞车；
2. **点开规则不可预期**——同一行不同区域行为不同（点项目行是展开、点卡行是进对话、点箭头是展开子卡），界面无区分；
3. **黑底灰字不可读**——次级说明字用 #484f58 落近黑底、11px，对比度约 2:1，低于可读阈值。

据此产出《主界面优化方案》（19,400B，含对测试空间 20 处 [T19] 改动批的完整甄别：B3/B4/B10 纠正、D1/I2/I5/I7 收编），2026-10-07 12:27 用户当场采纳并令「按这份方案，出实现方案，执行就行」。本实现方案即把该源方案落成可执行的施工上游。

不做会怎样：主界面继续停留在"能跑但第一次用看不懂"的状态——用户最在意的可懂性（这是什么、点什么会怎样、字能不能看清）三处硬伤长期挂账；对话区 IME 裸奔（中文输入法回车直接误发）、颜色/文字层级与规格 v4 不符等结构性缺陷不改。

对照源方案 §八的 N1-N12（导航判据）与 E-1~E-7（对话区/渲染健壮判据），全部写成可复跑断言：
