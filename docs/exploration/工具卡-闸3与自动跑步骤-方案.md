## 四、自动跑步骤方案

### 4.1 挂点结论

**不需要新运行时。** 「自动跑步骤」= 模型按步骤清单逐步发工具调用，由既有工具循环（第一节第 7 条）自动续跑。映射关系：
- 探针趟 = 既有 `tool_calls` 分支；
- 交付段 = 既有 `seats` 分支；
- **不新建任何循环**。

运行时选型由 session_041 与 card_020 定死：采用 E 探针制，不引入 ZhuGe 的 driver 或 think-tool。

### 4.2 设计点默认值

| 设计点 | 默认值 | 依据 |
|---|---|---|
| 触发方式 | 模型工具调用，不做 UI 按钮 | 与 E 探针制一致；工具循环无轮次闸（第一节第 7 条） |
| 步骤清单存放 | 职责区（卡身不装） | 卡身只写结论 |
| 步骤状态 | 落影子卡进度节 | 影子卡只写过程 |
| 步骤产物 | 经既有协议落卡 | 不新开协议 |

新增的只有两样：步骤清单的格式与存放位置、步骤状态。两者都是数据与提示词层的事，不涉及运行时改动。
