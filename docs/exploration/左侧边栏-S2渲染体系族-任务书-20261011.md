## 三、任务分解 T1~T5（按 M1/M2/M3 里程碑排，里程碑是内部验收点不是外部轮次）

### T1 · M1 状态基座（R-07/08/09/10）
**改哪里**：新建 `static/esm/state_layers.js`（~180 行）＋`static/esm/row_model.js`（~70 行）；`workspace.js` L420-423 四裸变量删除、L440-448 renderNav 改读新 store、L546-560 gotoCard 选中区接 store.select、L451-466 ensureCurrentPath 职责移入偏好层（source="system"）。
**改成什么**：
- `createNavStateStore()` 工厂，四区唯一 API：
  - 临时层（内存，不持久）：`temp.hover(cid|null)`／`temp.loading(cid,bool)`／`temp.error(cid,msg|null)`／`temp.loaded(cid,bool)`
  - 偏好层（localStorage，KEY=`nav.prefs.v1`）：`prefs.getExpanded(wid,cid)`／`prefs.setExpanded(wid,cid,"manual"|"system")`／`prefs.getProjectOpen(wid)`／`prefs.setProjectOpen(wid,bool)`——JSON 结构 `{expanded:{wid:{cid:"manual"|"system"}},projects:[],autoOrganize:true}`，**读写带 JSON 解析容错（坏 JSON 返回默认值不抛错）**
  - 选中层（URL hash）：`select.set(wid,cid)`／`select.get()`——复合键；旧 cid-only hash 回落当前页 WORK_ID
  - 快照层（服务端数据投影）：`snapshot.set(navData)`／`snapshot.get()`
- `createRowModel(card, store)` 零状态工厂：行对象只持不可变 card 引用与 children 投影；`props(store)` 实时投影六字段（expanded/source/loading/error/loaded/selected），全来自三层。
- **M1 结束时行为等价**（旧渲染函数改读新 store，innerHTML 拼装暂存不删）。
**明确不动**：L1112 轮询（M3 才换）；renderNavFromCache/renderCardRows 本体（M2 才删）；canvas.js；refreshBadge。

### T2 · M2 渲染换底（R-13/14/15/19）
**改哪里**：新建 `static/esm/nav_render.js`（~250 行）；删除 `workspace.js` L468-481 renderNavFromCache 与 L521-544 renderCardRows 的 innerHTML 拼装；**L602-634 事件监听改绑新 store**（展开/折叠/跳转/菜单调用新模块）。
**改成什么**：
- 行 DOM 用 `document.createElement` 构建（非字符串拼接）；mount/unmount/patch 三原语；首次挂载后**结构上无「重建整棵树」路径**。
- `fold(row)`＝该行 children 的 DOM 全部 remove＋临时层 loaded 清 false＋序列该孩子段移除；`unfold(row)`＝序列重建该段＋触发异步加载（未 loaded）或挂载。
- diff 模块：快照与 DOM 分离；三类变化（新增行 mount／消失行 unmount／字段变 patch）；**应用前检查 `store.temp` 交互集（hover/loading）——在集内则跳过该行本次 patch**（规则写在 diff 模块开头，不散落调用点）。
- **`export const RenderNav` 保留**（canvas.js 建卡后调用走 diff 路径）。
**明确不动**：L1112 轮询（M3 才换）；canvas.js；work.html。

### T3 · M3 规模机制（R-16/17/32/22/23）
**改哪里**：新建 `static/esm/nav_virtual.js`（~250 行，`createVirtualList(container, getRows, NAV_ROW_HEIGHT)`）＋`static/esm/nav_async.js`（~60 行，loadChildren 去重三态）；`style.css` .nav-card 补 `height:38px;line-height:38px`、.nav-ctitle 补 `white-space:nowrap`；api.js L100 后加封装；**L1112 替换为 `setInterval(probeVersion, 60000)`**。
**改成什么**：
- 虚拟滚动：可视区用**行数组前缀和**计算（混合行高：项目行 30px＋卡行 38px，非 38×n 公式）；行高常量 `NAV_ROW_HEIGHT=38`；DOM 行数＝可视区行数＋上下各 1 缓冲，与总行数无关。
- `loadChildren(row)`：模块内 `pendingLoads = new Map(cardId→Promise)` 去重（同节点重复展开共用同一 Promise，不发第二次）；三态就地（加载中＝行内转圈 `.nav-loading`／失败＝行内「加载失败·点此重试」灰字按钮＋复位／空＝叶形态 `.nav-twist.none` 展开箭头消失）；折叠即丢（children 数据丢弃、loaded 清 false，下次展开重拉）。
- `probeVersion()`：`API.getNavVersion()` → 与 `store.version` 比对 → 未变零开销（连 diff 都不跑）／变了 → `API.getNav()` 全量重拉 → 更新快照 → 用 `by_work` 对比旧快照哪几个 work 指纹变了 → **只 diff 变化的 work 子树**（未变 work 的 DOM 不动）；探测失败静默跳过（不 toast）。
- 默认折叠：所有项目行收起；当前项目（WORK_ID）展开一层（根卡直系）；当前卡祖先路径自动逐层展开（source="system" 记入偏好层）；**数量兜底 100**（同时展开超过 100 个系统展开分支时，自动收起最早的非路径 system 分支并提示，不打断用户）。
**明确不动**：refreshBadge（L1149-1210）；L801/L802/L912 其他轮询；.nav-phead 30px（L497 现状）。
