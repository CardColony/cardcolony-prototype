**要做什么**：按用户 2026-10-06 18:38 六条亲令（「接下来重新设计主界面，左侧改成对话导航」／「主界面按项目（剧本）组织」／「按最近活跃排序」／「左侧的卡片树可以展开折叠」／「各层级按活跃度重新排序」／附言「理解意图、更自主地思考」，20:12 令「那就出任务书吧」）〔C-001/C-002〕实现主界面重设计：三联外壳（左导航／中主视图／右 Inspector）＋ 一棵跨项目的活跃度排序导航树 ＋ 新增后端聚合端点 `/api/nav`〔R-009/R-010〕。

### /api/nav 契约字段级规格（B-4 实现依据）〔R-028/R-029/R-030〕

```json
{"projects": [
  {"work_id": "work_002", "title": "推演agent", "work_card_id": "card_001",
   "last_active_at": "2026-10-06T18:38:01+08:00", "card_count": 19,
   "cards": [
     {"card_id": "card_018", "title": "主界面设计", "parent": "card_007",
      "child_count": 0, "last_active_at": "2026-10-06T18:38:01+08:00"}
   ]}
]}
```

- **卡级 `last_active_at`** ＝ `max(该卡会话文件末条消息的 timestamp, 卡前置字段 updated_at)`；两来源均无 → 空字符串。
- **项目级** ＝ `max(该项目所有卡的卡级活跃, work.created_at)`；项目无卡无会话（空项目）→ 兜底 `work.created_at`。
- **时间格式** ＝ ISO8601 带时区（与 `session_store._now_iso()`/`datetime.isoformat()` 同源）。
- **排序**：`projects` 按 `last_active_at` 降序；每个项目 `cards` 按 `last_active_at` 降序（前端按 parent 归组后同级兄弟天然降序）〔R-029〕；无时间者排末位；并列以 `card_id`／`work_id` 升序稳定收尾〔R-030〕。
- **孤儿卡**（parent 指向已删卡）挂该项目根层末尾，不丢弃。
- **`/api/works` 同步**：附 `last_active_at` 并按活跃降序——两条路径口径一致〔R-031〕。

**任务 1 · 新模块 `activity.py`**（`src/storage/activity.py`，新建）〔R-038〕
- `card_last_active(work_id, card_id, updated_at) -> str`：取该卡会话文件末条 `timestamp:`（调用任务 2 的 `last_ts`），与 `updated_at` 取 max（ISO 字符串可比，同源格式），均无返回 `""`。
- `work_last_active(work_id) -> str`：遍历该项目所有卡，取卡级活跃 max；项目无卡 → `work.json.created_at`。

**任务 2 · `session_store.last_ts(work_id, card_id) -> str`**（`src/storage/session_store.py` 新增函数）〔R-039〕

**任务 3 · `work_store.list_works()` 附活跃并按活跃降序**〔R-031/R-040〕
- `list_works()`（work_store.py:49-71）：每项附 `last_active_at`（调 `work_last_active`）；排序由 `sorted(目录名)` 改为按活跃降序（并列按 `work_id` 升序稳定）〔R-030〕；`card_count` 保留。
- 本函数同时供剧本架页与 `/api/nav`——两条路径口径一致〔R-031〕。

**任务 4 · 新增端点 `GET /api/nav`**（`src/api/routes.py`，新增）〔R-040〕
