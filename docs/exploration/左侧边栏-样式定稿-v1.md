# 左侧边栏 · 样式定稿记录（v1 收官）

- 日期：2026-10-12
- 原型文件：`docs/exploration/左侧边栏原型-v1.html`（真实数据：13 个项目真名 + 项目管理agent 的真卡树）
- 自检：浏览器打开加 `?check=1`，机器断言全过（43 段线不压任何外列图标；根卡行无线；一级子卡行无拐弯线；每个父卡子列从父 icon 下缘连到末子 icon 中心不断线；出线不穿 icon 上半；运行中与时间互斥；箭头带咬断描边；每项目一张四圆角小卡片）

## 定稿决定（每条带为什么）

1. **整栏只有两样东西：一个搜索、一个列表。** 没有顶栏/工具栏/"你在哪"行——那些是从旧代码里抄来的壳，你要的四件事（接着干/看归属/打开卡/搜索）列表+搜索全覆盖，其余全是多余。
2. **每行只有：展开点 + 图标 + 名字 + 行尾状态。** 时间文字、卡数、状态文字全砍——位置本身就是时间（排序决定），颜色就是冷热；文字重复表达=抢眼睛。
3. **图标按"点它会怎样"分三类**：项目 / 普通卡 / 工具卡。有没有子卡由展开点表达，图标不重复这个信息。
4. **层级不用缩进**：字永远从同一条竖线开始；归属靠树线（连在 icon 上、从 icon 下边缘出发）+ 每层微推进 10px。缩进是宽度杀手，已废。
5. **项目根卡 ↔ 它的第一级子卡之间：不画线、不缩进。** 这一级是"打开项目"，不是"树往下钻"；正是这根线逼得整棵树的线绕来绕去。
6. **每个项目 = 一张四圆角小卡片**，项目之间的区分靠卡片本身，不靠间距。
7. **展开点 = 箭头**（全世界认识的"翻开/合上"符号），图案自带一圈与行同色的描边，把穿过的树线咬断，箭头与线分得开。**点名字永远 = 打开这张卡**，与有没有子卡无关——这是治"有子卡点不进去"的根。
8. **行尾：运行中只有转圈图标**（所有卡通用的状态：模型跑长活时亮），与"几小时前"互斥——正在跑的时候"上次对话时间"是冲突信息，跑完才显示时间。
9. **排序：最近活跃的排最上**（规则定死；"最后活跃时间"字段被刷权限脚本污染是数据端的事，单独修，不拖设计）。

## 边界（本轮不含，别混进来）

数据修复 / 自动组织（排序权重、自动收起、自动调位）/ 搜索进正文 / 归档档——都不在样式轮。

## 下一步：交互轮

交互轮1（本轮做）：
- 点击语义保持：点名字=打开、点箭头=展开，两个热区互不干扰
- 展开/收起后**不丢状态**：选中高亮保持、滚动位置保持（旧原型重渲染会丢，是 bug）
- 搜索升级为全树命中：命中藏在折叠分支里的卡也能看到（自动把它的上级路径显出来）、命中字高亮、Esc 清空、Enter 打开第一条
- 打开卡 = 当前卡定位：自动展开它的路径、滚动到它、高亮它
