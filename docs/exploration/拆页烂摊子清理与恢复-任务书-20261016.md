## 阶段 1 · 找 workspace.js 的"拆页前最后可用版本"（最关键，先做）

拆页手术把 workspace.js 从 ~1780 行砍到 ~1100 行（删掉导航段、hash 机制等）。**不能直接 `git checkout HEAD`**，因为 HEAD 可能缺 10-15 未提交的左栏最新改动（⋯、接线、根卡同构）。所以先找"拆页前那一刻"的版本。

**候选逐一核对（按优先级）：**
1. `_e2e_static_tmp_dsh/workspace.js`、`_e2e_static_tmp_ss/workspace.js`（若存在）——e2e 快照，可能是完美靶子
2. `git stash` 展开检查 —— stash@{0}（"并行会话改动归档 2026-10-16"）里有没有拆页前的 workspace.js
3. HEAD `042c0bb` 里的 workspace.js（~1780 行）

**每个候选查三样特征（决定它能不能当靶）：**
- ① 行数：~1780 = 未手术（可用）；~1100 = 已被手术（不可用）
- ② 含不含 `from "./nav_system.js"`：含 = 手术版（不可用）
- ③ 含不含 `data-newchild` / `.nav-plus` / `wid + ":"`：含 = 含最新左栏成果（优先选）

**选靶判定：**
- 优先选"未手术 且 含最新左栏"的候选。
