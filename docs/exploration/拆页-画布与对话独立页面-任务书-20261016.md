## 0. 任务定义（照方案 §0）

画布和对话各自成为有独立 URL 的网页：`/work/{wid}`＝画布页、`/work/{wid}/card/{cid}`＝对话页；URL 即页面身份，刷新各回各家；hash 机制退役（客户端兼容重定向）；两页各自只装自己的代码（模块图机械断言）。

1. **禁 `git add -A` / `git add .`**——每次提交用显式文件清单（beb408c 混提交教训）。
