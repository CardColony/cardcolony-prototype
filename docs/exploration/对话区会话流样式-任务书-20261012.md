## 一、任务清单（按序执行，每步完成即验收，不跳步）

### T1 新建 `static/esm/md.js`（零依赖 Markdown 渲染器）

**要求：**
- 纯原生 JS ES module，零第三方依赖，零外链（项目纪律：`static/esm/` 13 模块全自写；`style.css:3` 头注「纯原生 CSS，离线可用」）。
- 导出 `renderMarkdown(text) → html`。
- **escape-first 硬规则**：先整段 `escapeHtml`（复用 `static/esm/util.js:2-6` 的五字符转义，或内部等价实现），再解析生成结构；**不渲染原始 HTML**。顺序写反即 XSS，验收 V2 卡死。
- 支持语法：标题（`#`~`######`）、粗体、斜体、有序/无序列表（含嵌套一层）、表格（对齐冒号可忽略，竖线分隔即可）、行内码、围栏代码块（保留语言类名）、引用、水平线、链接（输出 `<a>`，`target="_blank" rel="noopener"`）。
- 代码量级约 200 行（规格定案「约 200 行零依赖独立函数」）。
- 文件头注释：模块名、日期、用途、escape-first 说明。

### T2 改 `static/workspace.js`

## 三、约束（违反即返工）

1. **不变量六条**（方案 §七）：容器数 0 不得重开；次序铁律：本轮过程行恒在本轮正式回复之前；数据层零写；回读链不变（`restoreFromHash → open → renderChat`）；卡间消息路径不动；流式机制不动（`.live` 期间 textContent 累加、仅接管时渲染一次）。
2. **escape-first**：任何路径不得先解析后转义。
3. **零依赖**：不引第三方库、不引 CDN、不加外链。
4. **范围禁越**：工具行收口 / thinking shimmer / 日分隔 / 面包屑 / 相对时间 / 过程痕迹持久化 / 工具信息收口 / 用户消息形态 / 卡间消息 / 三席思考行 / 左侧边栏 / 画布——一律不做（方案 §七不做清单）。
5. **用户侧只动宽度**：`.msg.user` 除随 `.msg` 共享的 width 规则外零触碰。
6. **版本戳同步**：资源文件改动必须升对应 `?v=` 戳，否则浏览器缓存导致不生效（work.html 两行）。
