## 〇、总则（先读这个）

**完全照抄的定义：**
dsh ui-conversation 的模块结构、状态机、交互逻辑、样式数值，**一比一移植**到本项目（原生 ESM JS + 手写 DOM，无 React）。
- dsh 的文件怎么切，我们就怎么切：**文件级对照表**（§二），文件名都对上
- dsh 每个状态、每个转移、每个事件分支、每个 CSS 数值，移植时**逐行有原文对应**
- **无原文对应的可以写，但必须先列入 §四b 自创清单、逐项给理由，经用户认可才写**；清单之外的自创一律不写（2026-10-17 13:17 用户裁定）
- **本项目此前自创的对话流代码全部退役删除**（§三），不是「兼容保留」

**唯一的适配层（允许改写的地方，仅此一层）：**
数据接口——dsh 喂 React 组件的是 dsh 自己的消息流；我们喂的是本项目 timeline 记录（29 类）＋SSE 帧。适配层只做一件事：**把 timeline 记录映射成 dsh 视图消费的节点/事件**。映射表见 §四。
适配层之外（状态机、输入、排队、渲染、滚动、样式）：零自创。

**语言载体说明（不是偷工）：**
dsh 是 React（tsx + hooks + CSS Modules），本项目是原生 JS。React 组件的字面代码抄不进原生 JS——所以「逐行照抄」的载体是：**同一套状态集、同一套转移函数、同一套事件处理分支、同一套样式值**，用原生 JS 表达。验收标准就是 §五 的行为逐项对照——dsh 什么行为，我们就什么行为，一项不缺一项不加。
