## 〇、一句话

左侧边栏是这套系统里唯一一个「项目维显式在场」的视图。它的最优解：**数据自带归属、状态落在行对象上、渲染只存在用户视野那一部分**——成本与视野成正比，与总节点数无关。

## 一、交互五条宪法（这一层的地基）

1. **落点唯一**——每个动作的输出只能是"一个明确的目标"；跨项目语境下目标由复合键（work_id＋card_id）唯一指认。
2. **原子、可预期**——同一状态、同一动作、同一结果；外部刷新不打断用户动作。
3. **状态与数据分离**——用户视野是私人状态（本地），绝不写系统数据。
4. **三问永远有答**——我在哪／下面有什么／怎么回去，界面始终答得出（祖先链显式在场）。
5. **为规模而生**——每个交互都在千级节点下检验过才配存在。

## 二、底座四件套（v1，保留）

### ① 数据契约：树形快照，节点自证归属
- 每张卡自带 `work_id`（归属由给数据的一方声明，拒绝用方各自推断）
- 项目内 parent 用裸 card_id 合法；跨项目一律复合键 work_id＋card_id
- 字段克制（借鉴 Codex L：「production wire intentionally implements only the methods required」）：work_id/card_id/title/parent/child_count/last_active_at/branch_active_at——不加装饰字段

### ② 状态模型：三层自治＋行对象四态
- **三层**：临时（滚动/悬停/搜索词，不持久）、回看偏好（展开/折叠视野，localStorage）、选中（URL，可回退可分享）
- **行对象四态（借鉴 ZCode model.ts L14-20）**：每行对象自带 `expanded/loaded/loading/error` 字段——行状态是行自身字段，不是全局孤岛
  - 归层：expanded→偏好层；loaded/loading/error→临时层
  - 行对象是渲染期派生数据（数据快照＋展开态合成），不是新状态源；三层容器仍是唯一读写口
- 硬规矩：定时刷新绝不碰任何状态

### ③ 渲染模型：按需更新、折叠即卸载、版本号探测
- 视图变化只增删改对应节点，**结构上没有"重建整棵树"这个动作**
- 折叠即卸载：折叠的子节点 DOM 移除，数据丢弃
- **数据刷新（借鉴 ZCode constants.ts L6-9 + useWorkspaceFileTreeData.ts L33-53，改造）**：60 秒只探测一个轻量版本号/最新 mtime——没变零开销；变了才重拉＋diff，diff 只更新变化字段，且**跳过正被交互（悬停/加载中）的节点**
- **虚拟滚动＋吸顶路径条（借鉴 ZCode useWorkspaceFileTreeStickyFolders.ts L3/L40/L97-99，修正 v1 否定）**：虚拟滚动基于"展开后的行序列"（折叠行不在序列里，与折叠即卸载天然咬合），只渲染可视区；吸顶路径条＝滚动时祖先路径悬浮顶部（与面包屑合并，不设两套）；固定行高 38px 单行是前提

### ④ 扩展点：四样增长各占各的层
数据往字段长、状态往行对象/三层归层长、渲染往节点级长、交互往事件层长——互不交叉；新功能只动自己那层。

## 三、手眼路径（v2，含 F 借鉴补入）

- **进来**：第一眼只看到当前项目（默认展开它，其他项目只有项目行）；当前卡唯一高亮＋祖先路径自动展开
- **定位**：唯一最强高亮＋祖先路径自动展开＋面包屑路径条（深树才显）＋「定位到当前卡」一键
- **找**：顺树翻／搜索直达（独立结果层覆盖树、结果带项目名、搜索不改造树）／最近访问（自动记 5-10 条）
- **去（点击语义按类型分叉，借鉴 ZCode WorkspaceFileTreeRowView.tsx L136-153）**：
  - 项目行单击＝展开/折叠（不跳转）
  - 有子卡的卡行单击＝展开/折叠
  - 叶子卡单击＝跳转（页面＋左栏一致更新）
  - **已删卡＝灰态，点击不跳**（不落到不存在的卡上——防"改的东西全丢"）
  - 跳转失败/目标已删：就地灰态置灰＋清选中＋面包屑回父卡，绝不假装成功
- **组织**：单点展开／一键收起到根／折叠记忆自动存（偏好层）
- **回来**：只记两样——树形视野（偏好层）＋当前选中卡（URL）；搜索词/滚动位置不记
- **多项目并看**：同时展开多个项目互不干扰；切走一个，它的展开态原样保留

## 四、万级节点机制（v2 主体＋E 修正）

- **异步加载**：点开节点→才拉它的下一层直系子卡（`/api/nav/children?work_id&parent`）；不预拉（猜错白拉）；折叠即丢数据（不淤积）
- **加载三态**：加载中＝行内转圈＋同节点请求去重；失败＝行内「加载失败·点此重试」灰字＋复位；空＝变叶形态（展开箭头消失）
- **默认折叠**：项目行收起；当前项目展开一层；当前卡祖先路径自动逐层加载展开
- **搜索/直达＝主通道**：深树找卡主入口是搜索直达/最近访问/收藏，不是逐层点开
- **主动降级**：同时展开超阈值（如 150）→自动收起最早的非路径分支＋提示，不打断

## 五、信息呈现（v2＋B/C/H/I 借鉴补入）

- **层级**：缩进只到第 4 档；更深用**引导线**——单个 repeating-linear-gradient 竖线背景（借鉴 ZCode hierarchyGuides.ts L1-15），宽度=深度×档距，替代逐层缩进块
- **标题**：一律单行截断＋悬停全称；不换行（行高恒定是虚拟滚动前提，红线）
- **徽章（常态≤2＋聚合）**：
  - 项目行＝**子树聚合**（最新活跃时间戳＋总卡数，机械取 max，不涉语义判断）＋「空·去新建」可点击（借鉴 H）
  - 节点行＝活跃标记（自身）
  - 砍：节点级子卡数字（箭头已表达）、规则注入状态（使用无行动价值）、类型（不常显，只在过滤时以文字出现）
- **高亮**：只有一处最强（当前卡）；当前项目次强；其余平凡
- **非正常态（借鉴 H）**：行内就地呈现——加载转圈（行内）／失败可重试（行内灰字＋点击重试，不静默不弹窗）／空项目=「空·去新建」可点击；不整栏闪烁

## 六、扩展点（G 键盘，第三期）

键盘第一交互列为扩展点第三期：j/k 上下、enter 展开、/ 搜索、tab 切面板——本轮主设计先走鼠标基础路径，键盘作为可加层，实现简单、价值明确，但不贪多（借鉴 Codex L：接口克制同样适用于交互面）。

## 七、失败边界（八条，如实）

1. 版本号探测也有网络往返；高频变化期重拉+diff 压力累积——探测频率届时可配，diff 合并批次（如实标，未完全闭合）
2. 吸顶路径条与虚拟滚动的视觉/点击重叠——ZCode 先例可抄（原行保留、CSS sticky 视觉覆盖、探针按行高触发），移植效果未在本机验证（如实标）
3. A.loaded 与数据过期：折叠丢数据后重新展开——定案：一律重拉（一致性优先），接受毫秒级等待
4. diff 与悬停竞态：悬停节点登记进状态层、diff 跳过——闭合到"登记即跳过"粒度，行内浮层是否闪未浏览器验证（如实标）
5. 搜索临时展开的回滚快照：搜索前记展开快照、关搜索回滚——多一份状态，实现时验证（如实标）
6. 列表里出现空卡（两次取数间卡被删）：F 已覆盖"点击已删卡不跳"；列表条目空掉未单独覆盖，归入 diff"消失节点移除"路径（如实标）
7. C 聚合口径：一棵子树同有 last_active_at 与 branch_active_at——取更近者（机械 max），定为实现时第一件事再钉一次语义
8. 万级全展开企图：主动降级兜底（自动收起最早非路径分支＋提示）

## 八、明确不解决的

多用户/多设备（本系统无用户概念）；实时推送（文件即数据，变化靠发现，轮询版本号是本性适配）；内容层（预览/编辑——职责已划走）；键盘（扩展点第三期）。
