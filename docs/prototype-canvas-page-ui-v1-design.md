## 一、模块架构

单文件内六个 IIFE，按「数据 → 状态 → 渲染 → 交互 → 覆盖层 → 左栏」单向依赖排列，**上层不回调下层渲染函数**。

| 模块 | 职责 | 明确不做 |
|---|---|---|
| `DataLayer` | 演示数据面（15＋N 张卡、归档记录、事件日志、对话、规则卡）、模型清单、类型枚举 | 不碰 DOM |
| `StateLayer` | 纯函数增量应用（`apply()` **唯一入口**）、折叠/打包/归档/模型覆盖等状态、`visibleIds`／`childrenOf`／`childrenOfSorted` | 不碰 DOM、不持视图变换 |
| `App` | 画布布局（band/place）、节点 DOM、连线 SVG、LOD、束渲染、顶栏统计、底部模型条、内置自测 | **不渲染左栏**、不管面板开合 |
| `Overlay` | 右缘全部覆盖层：**唯一状态机、唯一宽度表、唯一 `--paneW`、唯一互斥**、书签跟随、画布让位 | 不碰任何面板内容 |
| `Interact` | 画布手势、卡交互、命令面板、tooltip、各面板内容渲染（经 `setRenderer` 注册给 Overlay） | 不自算面板宽度/位置 |
| `RailView` | 左栏树（本版已从界面移除，模块保留，host 不存在即早退） | 不调 App 任何渲染函数 |

**分层纪律**：业务权威状态的唯一写入入口＝`StateLayer.apply()`（13 类增量）；视图变换（平移/缩放）走 `App.applyView()` 的渲染层直通路径，不进 store，不触发逐帧全量重渲染（T3 两半均满足）。

## 四、卡面解剖

**结构卡**（`290×84` 世界坐标，随内容放宽至 316）：

```
┌ [类型图标 24] [状态点 7px] [标题] …………… [卡号 mono 10px] ┐
│ （运行中）推流一行（marquee 流过，reduced-motion 下静态可读）  │
└ [card_id] [模型徽标] [悬停三钮 ◧ ▣ ✎] ──────────────────┘
```

- **状态**：只以**颜色点**表达（运行中 7px 呼吸 + 卡面左缘流光；受阻红；暂停琥珀；排队三格跳动动图；一轮完工蓝点阅后即消；整卡完工灰点 + `done` 记号），状态词不进卡面（R9 口径：词由服务端 `display_word` 算，前端不自造）。
- **悬停三钮**：◧ 对话／▣ 归档（根卡无）／✎ 编辑卡面——**仅 full／ultra 档可见可点**，far／near 档不渲染（`@309／@313` 断言在面）。
- **模型徽标**：far／near 档纯展示且 `pointer-events:none`（`@316／@719`），覆盖值带「覆盖自类默认·<类默认名>」。
- **继续钮**（暂停卡常显）：**34×34 中性圆钮**、`--brand-gold` 橙、无外圈（`border:0`／`box-shadow:none`）、无文字，位置＝**卡身右侧垂直居中**（`right:8px; top:50%`），与折叠钮／动作行／模型徽标均不抢位。
- **排队动效**：三格跳动，位置与继续钮同槽（`right` 侧、垂直居中），两者互斥。
- **`done` 记号**与子卡数徽标分行不叠：`done` 占行内位、子卡数在折叠钮侧。

## 六、折叠与「同级打包」（束）

> 本节是本版最反复的一处，最终照 `推演agent`（运行中 Agent）左栏 `quietfold` 的源码机制实现。

### 6.1 两种折叠语义（不可混用）

| | 子卡折叠 | **同级打包（束）** |
|---|---|---|
| 对象 | 一张卡自己的子卡 | **同一父卡下、完成的同级兄弟卡** |
| 控件 | 卡头 ▾／▸ 折叠钮（箭头 + 子卡数） | 一个**常驻的束** |
| 判据 | 有子卡即可 | **四类执行卡**（worker/ui/qa_card/pm_card）＋ 已完成 ＋ 非当前打开；**≥1 张即折**。结构卡不打包 |
| 位置 | 卡内 | **段尾**（同级运行卡之后，完工卡沉底） |
| 效果 | 该支子卡不渲染 | 同级完工卡只占**一格**（世界高 44px），省空间 |

### 6.2 束的表达

- **形状**：三层错边小卡叠——底层两张暗卡与顶层同尺寸（`calc(100% − 10px)`），错位 **5px / 10px 等距**，暗卡大半藏于顶层下、只露右下窄边；暗卡 `color-mix(surface 88%, transparent)`、透明度 `.55/.8`。
- **折叠入口卡条**（`.pk-top`）：**虚线**边框（`1px dashed --stroke-strong`，表达「这是入口不是真卡」）；卡条**中央**一个**上下折号 chevron**（`M6 9l6 6 6-6`，收起朝下；`.is-open` 时 `rotate(180deg)` 朝上），**张数数字贴在箭头右侧 8px**，两者作为整体居中（`justify-content:center; gap:8px`）。
- **常驻与双向**：散开后束**不消失**、留在原位（`is-open`），成员各自占格排在束前；再点束＝重新归拢。整条命中区就是开关。
- **归属线**：`drawWires` 为束补**父卡右缘 → 束左缘**的连线（打包态/散开态均在），束不孤立。
- **命中区**：世界高 44px（56% 档 ≈24.6px）＋ `::after` 反向放大热区，保证任何档 ≥24×24。

### 6.3 沉底

`StateLayer.childrenOfSorted` 让**同级 completed 排最后**，仅布局层（`band`／`place`）使用——连线、折叠、统计仍用 `childrenOf` 保持插入序，互不影响。

## 八、覆盖层（Overlay）

唯一状态机管四窗（搜索／事件／规则／归档）＋对话浮窗＋卡面编辑面板＋命令面板：

- **宽度表唯一**：`WIDTH = {search:404, events:404, rule:404, archive:404}`（按正稿 R22 统一为 404）。
- **几何唯一**：`.float,.dock` 共用一套 `transform + visibility` 过渡（`.28s` 滑入），不硬弹。
- **互斥唯一**：同时至多一窗；打开入口**只开不 toggle**（关闭走面板 ✕ 或 Esc），避免重复 click 自我抵消。
- **书签跟随**：`shiftBm()` 直接读面板 `getBoundingClientRect()` 写 `.bm.style.right`（不依赖 CSS 变量继承链）；实测面板 left=836／书签 right=831，紧贴 5px。
- **画布让位**：`canvas.style.right = w + CHANNEL(52)`，按「本次宽度差/2」在 `applyGeometry` 内算，删除所有 `setTimeout` 补算。

**已知缺陷**：`.float` 容器 `bottom:0`（@355），浮窗延伸至视口底，与底部 44px 模型条（y≈756–800）重叠 → R22「下缘留位 ≥64px」**未达**。
