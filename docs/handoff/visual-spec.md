# CardColony 视觉规范（Design Tokens）

> 真源：`docs/prototype-canvas-page-ui-devin-v4-paper.html`（单文件可执行稿）。
> 本文档所有色值/尺寸均为该文件内实测值，非约数。令牌名沿用原型变量名，
> 前端实现可直接映射为 CSS custom properties / design tokens。

## 1. 设计基调

- **平级面板化**：画布、左侧列表、对话区是同层级的兄弟面，无浮层、无阴影遮盖、
  无圆角悬浮卡。面板"推出"挤占布局而非覆盖。
- **纸面感 + 黄卡**：日间态白底，卡片是唯一着色的面（淡黄 `#fffbe9`）。
  黄色只属于"卡的实体"，不用于选中态、信函等交互面。
- **金作细笔**：品牌金只做窄条/点/小面积强调（当前条、受阻文、运行信号），
  不铺大面积半透明洗。
- **双主题**：`[data-theme="light"|"dark"]` 切换，令牌同名双套值。

## 3. 字体系

| 用途 | 字栈 |
|---|---|
| 正文 | `13px/1.5 "Segoe UI","PingFang SC","Microsoft YaHei",system-ui,sans-serif` |
| 等宽（id/计数/时间/代码） | `"Cascadia Mono",Consolas,monospace` |

字号阶梯：10px（徽标/计数）· 10.5–11px（书签/弱标签）· 12–12.5px（辅文/面包屑）·
13px（正文）· 14–15px（卡标题/顶栏品牌）· 18px（Master 卡标题）。

## 5. 阴影 / 动效

- 卡片静态：`--cardsh: 0 1px 2px rgba(75,65,45,.10), 0 3px 10px rgba(75,65,45,.07)`；
  悬停 `--cardshh` + `translateY(-1px)`。
- **面板（列表/对话/抽屉）一律无阴影**——同层平级。
- 运行中卡：边框环流光束 `conic-gradient` 巡边 `2.8s` + 状态脊脉冲 `2.6s`。
- 排队卡：脊脉冲 `1.2s` + 三跳点 `qb` 动画。
- 场务签 `live` 点：`qb 1.6s` 闪烁。
- 新卡生长：`spawn .35s cubic-bezier(.2,.75,.3,1)` + `fring 2.2s` 余晖。
- 面板推出：`.22s ease`（max-width）；抽屉让位同步 `.18s`。

## 6. 选中 / 悬停

- 左列表当前行：`--selbg` 浅灰洗底 + 左缘 `--gold` 金条 `inset 2px 0`；
  图标 underlay/图标配底同色保证树线穿叠连续。
- 行悬停：浮出 `⋯`（菜单）/`＋`（加子）两枚隐形钮。
- 卡悬停：描边加深 + 阴影升级 + 上浮 1px。
- 场务签悬停：描边变实体色 `--vc`。

## 7. 图标

`assets/icons/`：类型图标 `type-{master,manager,unit,worker,qa,pm,ui}.svg`；
左栏图标 `nav-{chevron,folder,doc,worker,ui,qa,pm,dots,plus}.svg`。
全部 16px 视窗 `stroke=currentColor` 描边系，随文字色继承；
类型图标在画布卡/左栏/图例三处共用同一份。
`assets/logo.svg`：CardColony 标（C 形 + 双金瞳 + 天线点），22px 顶栏用。

## 8. 无障碍基线

- 三级文字对比度 `--tx3` 白底 ≈4.7:1，`--tx2` ≈6.7:1。
- 状态除色彩外有形状编码（脊/点/徽标字），受阻卡额外红字+红底 `color-mix(--blk 9%)`。
