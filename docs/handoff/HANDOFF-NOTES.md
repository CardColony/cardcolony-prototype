# 交接注意点（前端实现前必读）

## 1. 数据口径：mock 与真实模型的差异

原型用四个 mock 数组驱动全部渲染，实现时不要照抄数据形状：

| Mock | 真实模型 |
|---|---|
| `CARDS[]`（树内） | cards 表 = 唯一卡实体；树形靠 parent 指针 |
| `RV[]` / `AL[]` / `FN[]`（离树） | 三种**场务实体，不是 card 类型**：评审挂目标卡 `target`、对齐场挂成员、职能挂派驻点 `venue`。它们出现在画布签/左栏尾行/对话浮窗，但绝不进 cards 表、不参与树布局。 |

卡面只呈现三态信息（无信息/流式/截断未读）是产品铁律，不是实现细节。

## 2. 真实现文件映射（可直抄的部分）

原型里的类名、令牌名、几何算法取自既有实现，以下文件是一一对应源：

| 原型块 | 真实现 |
|---|---|
| 左列表渲染 + 树线几何（indentOf/iconX/rowSegs/30px 行高） | `static/esm/nav_render.js` + `nav_geo.js` |
| 对话流（msg/cmsg/step/think/tool 节点） | `static/esm/stream.js` + `card-msg-node.js` |
| 列表/导航样式 | `static/nav.css` |
| 对话/面板/令牌样式 | `static/ui.css`、`static/paper.css` |
| DOM 骨架（`.pz`、flow-view、topbar、input-card） | `templates/card.html` |

`.pz` 域的中性令牌（`--ui-*`）在原型中已**别名到画布变量**——实现时直接
建一套统一令牌，不要复刻两域桥接。

## 3. 容易做错的点（验收清单）

1. **logo 只渲染一次**：通栏顶栏里的同一元素，列表从顶栏**下方**推出，
   不许盖 logo、不许在列表头重画一份。`.brand-zone` 定宽 272 = 列表列宽。
2. **三面板同底同级**：列表/画布/对话共 `--bg`，推出=挤占（`max-width`/
   `stage right` 让位），无阴影、无圆角浮卡、无遮罩层。
3. **黄只在卡实体**：`--cardbg` 用于画布卡和左栏当前签；选中行/卡间信用
   `--selbg` 浅灰——两者不同色，不混用。
4. **发送钮专属蓝** `--sendbg`；金 `--gold` 只做细笔（logo 点/当前条/受阻文/
   运行点），不铺大面积洗底。
5. **画布左缘 14px 热区**呼出列表，不是必须命中 ☰；移出 120ms 防抖收起。
6. **对话页顶栏是 ☰→画布钮**，且面包屑段/分隔符同高 26px 垂直居中
   （`.cseg`/`.csep` 均 flex）。
7. **fwin 是例外**：评审/对齐窗保持浮窗形态（临时场），不并成平级面板；
   全幅态向左长到 `min(56vw,900px)` 挤正文。
8. **fn 档案面板要钳位**视口内（`top ≤ innerHeight-面板高`）。
9. **状态信号双层**：状态脊（色条）+ 信号动效（run 光束巡边、qed 三跳点），
   色彩障碍用户靠形状/动效可辨。
10. **深色态 `--cardbg`/`--selbg` 落回深色面**——黄卡/浅灰是日间专属。

## 4. 原型行为即规格的部分

以下行为在原型中是完整实现的，实现时作为交互规格而非参考：

- 单击卡=开对话、双击=子树收展、拖到卡上=改归属
- 打开卡即标已读（消卡面 `.unr` 预览 + 左栏未读泡）
- `⌘K` 命令面板、`F` 整幅适配、Esc 关一切
- 左列表悬停 `⋯`/`＋` 行内钮、挂列（collapsed）置灰镜像
- 面包屑跳祖先、过程细节钮一键收全部过程件

## 5. 不包含在本包内

- 后端 API / WebSocket 协议：看 `D:\CardColony` 工程侧（protocol/channel/gate）。
- 自主演示（▶自动）的生长编排：纯前端 mock 导演逻辑，实现侧归产品排期。
- i18n 字典：原型为中文硬编码，实现接 `static/esm/i18n.js`。
