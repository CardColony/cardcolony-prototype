# CardColony 页面与交互规格

> 真源：`docs/prototype-canvas-page-ui-devin-v4-paper.html`。
> 页面截图见 `assets/slices/page-*.png`，元素切图见 `assets/slices/el-*.png`。

## 1. 应用骨架

```
┌ .top（通栏顶栏 44px，logo 唯一元素恒在 x=14，永不被盖/重画）┐
├──────────────────────────────────────────────────────────┤
│ .body（flex 行）                                            │
│ ┌ .navw（272px 左列表，画布态 max-width:0 收起）┐ ┌ .core ┐ │
│ │                                            │ │ 视图区 │ │
│ └────────────────────────────────────────────┘ └────────┘ │
└──────────────────────────────────────────────────────────┘
```

- **单页两视图**：`data-view="canvas"` / `"chat"`，同一 DOM 树切换，无路由跳转。
- 顶栏按视图互斥显示两组件：`.top-canvas`（画布：☰+全景+统计+缩放+控件）/
  `.top-chat`（对话：画布钮+面包屑+过程/主题/详情钮）。
- `.brand-zone` 定宽 272px = 左列表列宽，logo 靠左、视图切换钮顶到列右缘——
  它是列表的"列头"，不是顶栏的一部分。
- 三要素"同层平级"：列表/画布/对话共享 `--bg` 一张底，无阴影、无圆角悬浮、
  无遮盖；推出=挤占布局（`max-width` 动画 / `stage right` 让位）。

## 2. 视图一：画布（全景树）

`assets/slices/page-canvas.png`

- 无限平移/缩放舞台（`.stage` 世界坐标 + `transform`），树卡按层级
  master 360 → manager 330 → unit 310 → 执行卡 tok 300×34 排布。
- 卡间连线（`#wires` SVG）走正交折线，色 `--wire`。
- 卡面三态信息（产品铁律）：
  1. **无信息**：空白卡面；
  2. **运行中**：流式进度行（滚动）；
  3. **已完成/新一轮未读**：静态截断开头（`✉ 发送者·类型` 前缀）。
- 状态脊（卡左 4px 圆条）+ 状态语义：
  `run` 边框光束+脊脉冲｜`blk` 红底 9%+红字｜`pau` 灰｜`qed` 快脉冲+三跳点｜
  `done` 收成单条+"done"小签。
- 画布上卡的**场务签**（`.c-venues`，顶缘右挂）：评审紫/对齐青/职能蓝，
  带 `计数`（2/4）和 live 脉冲点——挂在目标卡上不独立成卡。

### 2.1 左列表（项目树）

- **呼出**：画布态左缘 14px 隐形热区（`#navEdge`）或顶栏 ☰——hover 即开，
  移出 120ms 后自动收；推出挤压布画布（max-width 0→460px）。
- 结构（真实现同构）：`＋新项目` 主钮 → 搜索框 → 树行（30px 高）→
  尾部场务行 → 底栏设置。
- 树行：树线 segs（indentOf/iconX/rowSegs 几何）、折叠 chevron、
  类型图标+中文徽标（编程/QA/UI/PM）、`#001` 卡号+标题、
  尾槽三态（运行转圈/断连橘点/完工蓝点/相对时间）、悬停 `⋯`/`＋`。
- 当前行：`--selbg` 洗底 + 左缘金条；挂列（collapsed 子树）降级置灰。
- 尾部场务行（不进 cards 表）：
  `.nav-rvrow` 评审徽标+目标名+`2/4`｜`.nav-alrow` 对齐徽标+议题+`1/3`｜
  `.nav-frow` 职能徽标+**斜体名**+`已撤岗`置灰。
- 搜索框过滤命中高亮+自动展开；`＋新项目` 走 createProject 链。

### 2.2 右缘书签 + 抽屉

- `.re-group` 右缘竖排书签：事件/规则卡/归档（带计数泡）。
- 点开=右侧 `.drawer`（362px）**同级停靠**：画布右缘收 362px 让位，
  书签组跟着贴到接缝；无阴影、无圆角、无遮罩。
- `dr-conv` 卡片对话抽屉：头部（标题/⤢完整对话/✕）+ 消息流 +
  底部输入条（`.field` + 蓝发送钮）。

## 3. 视图二：对话页（card.html 真结构）

`assets/slices/page-chat.png`

- 顶栏对话组：`▦` 画布钮（回画布）+ 面包屑 `根 › … › 当前卡`（可点跳祖先）+
  右端 `过程细节 / 深浅主题 / 卡详情` 三钮。
- 信息流（`flow-view`，scrollbar-gutter 稳宽）：
  - **用户泡**：右对齐、白底 `--surface`+金细边，≤84%/720px，hover 出复制/重发；
  - **卡回复（assistant）**：裸文本左排 + meta 独立行（模型徽标+mtime，hover 提亮）；
  - **卡间信 `.msg.cmsg`**：`--selbg` 浅灰卡 + 左条色（ask 金/answer 绿/bad 红），
    头行 `msg_ask·询问·须回应 card_303→card_206`，`answer` 尾部"回应 cm_221"；
  - **过程件**：`.date-divider` 日期分隔、`.think` 折叠行（`0:07`）、
    `.step-row`（事件名悬停露/右缘点+词/可点开载荷）、`.tool-row`（✓ 2.4s+摘要）、
    `.flow-turn-status`（`Deep diving… 0:32`）、`.flow-queue-dock` 排队条；
  - **轮分隔**：`第 2 轮`。
- 底部 `.flow-input-card`：22px 圆角真卡——透明 textarea+caret，
  `.flow-input-backdrop` 显字、`.flow-input-mirror` 隐形量尺寸；
  下排 `需求确定/更新现状/手动模式` 胶囊 + 模型徽标 + `32px` 蓝圆 send ↑。
- **fwin 评审/对齐窗**（`.fwin`，浮窗属例外——真产品里"临时场"形态）：
  - 收缩态：右上小窗，脉冲点+`评审 2/4`+事件流水 3 条+live 行；
  - 全幅态：向左长到 `min(56vw,900px)` 挤正文，内容=评审卡自己的对话流+批次摘要；
  - 头行 `⤢` 展开 `×` 关闭；对齐窗同构青点。
- **职能档案**（`.nav-fn-panel`，360px 浮层）：职能号+派驻+状态丸（在岗/已撤岗）+
  职责书+迷你对话串；位置锚行并钳位视口内。
- **卡详情**（`.inspector`，右 352px 让位面板）：卡字段/模型/操作。
- 过程细节钮：整列 step/think/tool 件一键收起（`.proc-off`）。

## 5. 状态机要点

- **列表开合**：`navw.open`（仅画布态）｜hover 链：railHandle/navEdge/navw 三方
  `:hover` 均未命中 +120ms 防抖才收。
- **视图切换**：`openChatView(id)`（写面包屑/消息流/场务窗态/mark read）/
  `backToCanvas()`（关全部抽屉+inspector）；两视图不卸载，仅 `display` 切换。
- **未读**：`card.unread` → 卡面 `.unr` 预览行+左栏未读泡；进对话即清。
- **镜头**：跟随=导播自动调度；手动=用户接管（12s 无操作回跟随）。
- **自主演示**（▶自动）：生长/跑完/受阻/临时链路的整剧导演。
- **折叠**：卡双击或 `[+n]` 徽标切换子树收展，列表挂列同步镜像。

## 6. 数据口径（前端对接注意）

- 原型 `CARDS/RV/AL/FN` 为 mock：真实口径是 **cards 表 + 三种离树场务实体**
  （评审挂目标卡 `target`、对齐挂成员、职能挂派驻点 `venue`）——
  不要把场务做成 card 类型。
- 真实现同名结构可直抄：左栏 `nav_render.js`+`nav_geo.js` 几何、
  对话流 `stream.js`+`card-msg-node.js`、样式 `nav.css`/`ui.css`/`style.css`、
  骨架 `templates/card.html`——类名/令牌在原型中均为原值。
