## §3 改造清单（唯一允许动的文件：src/storage/card_store.py）

### 3.1 新增一个挂点函数（放在 `_meta_of` 之后、三个写函数之前）

```python
def _write_gate(work_id: str, action: str, card_id: str, payload: dict[str, Any]) -> dict[str, Any] | None:
    """写路径统一校验挂点（唯一门上的闸位）。

    当前为 no-op：恒返回 None（放行）。
    后续卡片分类基座 T3 在此挂 card_type 闸门：
    返回 None ＝放行；返回 {"error": ...} ＝拦截。
    """
    return None
```

**约束**：
- 函数名 `_write_gate`（模块内私有，不对外暴露）。
- 返回 `None` 表示放行；返回 `dict`（含 `error` 键）表示拦截。
- 本补丁**只放空转实现**，不写任何真实校验逻辑。

### 3.2 在三个写函数体内各插一处挂点调用

**插入位置**：每个写函数在**实际写盘之前**、参数校验之后。

**插入形式**（三处同构）：

```python
# create_card 内（action="create"，card_id 为新卡 id，payload 为待写字段）
gate = _write_gate(work_id, "create", <新卡id>, <待写字典>)
if gate is not None:
    return gate

# update_card 内（action="update"）
gate = _write_gate(work_id, "update", card_id, updates)
if gate is not None:
    return gate

# delete_card 内（action="delete"，payload 可为空 dict）
gate = _write_gate(work_id, "delete", card_id, {})
if gate is not None:
    return gate
```

**约束**：
- 每个写函数体内**只插一处**，插在写盘前。
- 挂点返回 `None` 时**必须落到原有逻辑**，一行原代码都不许改。
- 挂点返回非 `None` 时直接 `return gate`（本补丁下永不触发，因为挂点恒返回 None）。
- **不许改函数签名、不许改返回值结构、不许改任何调用点。**
